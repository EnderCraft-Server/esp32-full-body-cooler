# 接线总表 —— 逐触点（照这份文档就能把整机接起来）

> **85 根线，一根一行。** 全部以**物理触点**标识，不用元件上印的字。
> 例如 ESP32 不写 "GPIO5"，写 **`U1 · J1 第 5 脚`**（排针从上往下数）。

## 触点命名约定

| 元件类型 | 怎么写 | 例子 |
|---|---|---|
| ESP32 排针 | `U1 · J1 第 N 脚` / `U1 · J3 第 N 脚`（**从上往下数，第 1 脚在最上面**） | `U1 · J1 第 5 脚` |
| 继电器模块 | `K1 · IN 端子`、`K1 · COM 端子` 等（模块上印的端子名） | `K1 · NO 端子` |
| 降压板 | `PS1 · IN+ 端子`、`PS1 · OUT+ 端子` | `PS1 · OUT+ 端子` |
| 两脚电阻 | `R6 · 脚1` / `R6 · 脚2` —— 电阻不分极性，脚1/脚2 只是本表编号，**照表中"从/到"接即可** | `R6 · 脚1` |
| 二极管 | `D1 · 阳极（无环端）` / `D1 · 阴极（有银环端）` | `D1 · 阴极` |
| 三线传感器 | 按**线色**：`T1 · 红(VDD)`、`T1 · 黑(GND)`、`T1 · 黄(DQ)` | `T1 · 黄(DQ)` |
| 开关/按键 | `SW1 · 触点A` / `SW1 · 触点B`（两只脚不分） | `SW1 · 触点A` |
| 电池/保险丝/泵 | `BT1 · 正极柱`、`F1 · 进线端`/`F1 · 出线端`、`M1 · + 柱`/`M1 · − 柱` | `BT1 · 正极柱` |
| 汇流点 | 直接写母线名：`GND` / `+12V_F` / `5V_A` / `5V_B` / `3V3` | `5V_A` |

## 0. 先建 5 条母线（后面所有线都往这 5 点接）

| 母线 | 从哪来 | 供给谁 |
|---|---|---|
| **GND** | `BT1 · 负极柱` | 所有器件的 GND，**必须全部接过来** |
| **+12V_F** | `F1 · 出线端` | 两个降压板的 IN+、5 个继电器的 COM、分压 100k |
| **5V_A** | `PS1 · OUT+(5V) 端子` | 5 个继电器 VCC、5 只 10k、水流传感器 |
| **5V_B** | `PS2 · OUT+(5V) 端子` | **只给 ESP32 的 5V 脚** |
| **3V3** | `PS2 · OUT(3.3V) 端子` | DS18B20 VDD、4.7k 上拉、ESP32 3V3 脚 |

> 继电器线圈吸合瞬间会把 5V 拉出一个坑。ESP32 和继电器**不能共用一条 5V**，否则会复位。

**停下来量一下**（黑表笔接 GND）：

```
□ 5V_A   对 GND   4.9 ~ 5.1 V
□ 5V_B   对 GND   4.9 ~ 5.1 V
□ 3V3    对 GND   3.25 ~ 3.35 V
□ +12V_F 对 GND   = 电池电压（11 ~ 12.6 V）
□ 断电量 F1 出线端 对 GND 的电阻 —— 不能是 0 欧，否则是短路，别上电
```

> ⚠ **泵绝对不能从降压板取电。** 必须直连电池（经保险丝 + 继电器触点）。上一台泵就这么烧的。

## 3. 上电前 10 条检查

```
□  1. 泵的 12V 是从电池来的吗？中间只有保险丝和 K1 的 COM/NO？
□  2. 保险丝装在电池正极分流之前了吗？
□  3. D1 阴极（有银环端）朝 M1 的 + 柱吗？
□  4. K1 用的是 COM + NO，不是 NC 吗？
□  5. K1~K5 的 IN 都各有一只 10k 上拉到 5V_A 吗？（5 只）
□  6. U1 的 J1 第 22 脚（GND）和继电器模块的 GND 是同一个点吗？
□  7. U1 的 J1 第 21 脚（5V）接的是 5V_B，不是 3V3 吗？
□  8. 断电量 F1 出线端 对 GND 的电阻 —— 不能是 0 欧。
□  9. 泵放水里了吗？
□ 10. 手放在电池接头上，闻到糊味立刻断。
```

## 4. 最容易接错的 8 处

| # | 错在哪 | 症状 | 怎么查 |
|---|---|---|---|
| 1 | 漏了 **C30**（ESP32 GND） | 说 `pump=ON` 不吸合；说 `pump=OFF` 反而一直转 | 通断档量 J1 第 22 脚 和模块 GND，必须 0Ω |
| 2 | 10k 漏了或接成下拉 | 复位/烧录时泵自己抽一下 | 每只 IN 到 5V_A 之间必须有 10k |
| 3 | **D1 装反** | 一上电就烧保险丝 | 有银环那端朝 M1 的 + 柱 |
| 4 | 继电器用了 **NC 触点** | 断电时泵反而在转 | 换到 COM + NO |
| 5 | 泵从降压板取电 | 降压板冒烟、泵欠压堵转 | 泵 12V 直连电池 |
| 6 | 4.7k 上拉到 5V | J1 第 4 脚被打坏 | 必须拉到 3V3 |
| 7 | **排针数错一格** | 全乱 | 照第 1 节的逐脚表，**从最上面那个脚开始数** |
| 8 | 5V_A 和 5V_B 并成一条 | 继电器一吸合 ESP32 就复位 | 两条独立的 5V |

## 5. 接完之后的验证步骤

```
# 1. 只接电池 + 降压板，不接 ESP32：量 5V_A / 5V_B / 3V3 都对
# 2. 接 ESP32（USB 线先别插），上电，看板载灯
# 3. 插 USB 线（USB 那个口），开串口 115200：

scan                       # 应列出 5 个探头 ROM
map skin_chest 0           # 把 1 号探头绑成"胸前体表"（自动存 NVS）
relay test                 # 每 5 秒翻一次 IN，用耳朵确认哪次咔哒
pump on                    # 强制开泵
pump off                   # 应该真的停 —— 停了才说明驱动方式对
enable on                  # 打开自动控温
status                     # reason 行会直接告诉你为什么开/不开
```
