# PCB 设计规格书 —— body-cooler 全身降温器主控板

> **用途**：交给硬件工程师设计 PCB 的完整输入。
> **固件**：已完成并验证，引脚分配不可随意更改（见第 6 节）。
> **日期**：随固件版本同步更新。

---

# 1. 项目概述

背包式全身降温器。冰袋 + 水装在 PET 罐里，通过 **365 微型隔膜泵**把冷水打进贴在身上的 **8×11 软管**循环，
用 **DS18B20 温度探头**测水温和体表温度，**ESP32-S3** 通过**继电器**控制泵的间歇启停实现控温。

**核心约束（决定了整个设计）**：

| 约束 | 原因 |
|---|---|
| **泵不能用 PWM 调速** | 有刷电机换向器在 PWM 下剧烈打火；隔膜泵低速时阀片拍打异常。只能整段启停 |
| **控温靠时间比例** | 开关周期几十秒~几分钟，远大于电机热时间常数 |
| **电池背在身上** | 和水路在同一背包里，安全设计优先级最高 |
| **高湿 + 振动环境** | 冷凝水、身体晃动、软管拉扯 |

## 2.1 电流路径铁律（这条踩过坑，烧过泵和电源板）

```
✅ 唯一正确的泵电流路径：
   电池+ → 保险丝 → 继电器 COM → NO → 泵+ → 泵− → 电池−

❌ 绝对禁止：
   泵的电流经过任何降压板 / 电源模块 / 稳压器
   泵的负极经过信号地或控制板 GND 铜箔
```

**原因**：泵启动瞬间 2A（额定 450mA 的 4~5 倍），且是感性负载。
曾经因为把泵接在 12V 降压板的输出上、且没有保险丝、没有续流二极管，
结果**泵和电源板同时烧毁**。

# 3. 电气总规格

| 项目 | 值 |
|---|---|
| 输入电压 | 9.0 V（3S 放空）~ 12.6 V（3S 满电） |
| 输入保护 | **5A 快熔保险丝**（板载或座子） |
| 主负载 | 365 隔膜泵，12V / 450mA，启动峰值 ~2A，感性 |
| 5V 轨总电流 | ESP32 ~120mA + 5 路继电器模块 ~425mA（全吸合）≈ **550mA**，峰值 700mA |
| 3.3V 轨 | 由 ESP32 模组/开发板上的 LDO 产生，**板上不要另做 3.3V 供 MCU 主电** |
| 工作温度 | 5 ~ 45 ℃（贴近皮肤 + 冷凝水环境） |
| 工作湿度 | 高湿，**必须做三防漆** |

## 3.1 电源树与电流预算

| 轨 | 来源 | 负载 | 稳态 | 峰值 | 建议能力 |
|---|---|---|---|---|---|
| +12V | 电池（经保险丝） | 泵 | 450 mA | **2 A** | 走线 ≥2A，自己一条 |
| +12V | 同上 | 5V 降压 ×2 | 0 | — | |
| 5V_A | 降压路A | 5 路继电器线圈 + 光耦 | 425 mA | 500 mA | **≥2 A** |
| 5V_B | 降压路B | ESP32 + 探头 + 传感器 | 120 mA | 200 mA | **≥1 A** |
| 3V3 | ESP32 板载 LDO | DS18B20 ×5 + I2C 上拉 | 10 mA | 50 mA | — |

**为什么两路 5V**：泵启停会在 12V 母线上产生尖峰，经降压器耦合到 5V。
共用一路时表现为 **ESP32 随机复位**。分路后 ESP32 拿到的是干净电源。

# 4. 板上必须实现的电路（PCB 设计要点）

## 4.1 泵驱动回路

**方案 A（推荐，沿用现有模块思路）**：板载 5V 继电器 + 驱动

```
                    ┌──────────────────┐
  +12V ──[F1 5A]────┤ COM              │
                    │  继电器 K1        ├─── NO ──┬──── 泵+
  GPIO5 ──[R 10k↑5V]┤ IN    线圈+ ──5V  │         │
                    │       线圈− ──GND │      ┌──┴──┐
                    └──────────────────┘      │ D1  │  1N5822
                                              │ 反向 │  阴极(有环)朝 +12V
  泵− ─────────────────────────────────────────┴──┴──┘
```

**必须有的三个元件**：

| 元件 | 参数 | 作用 | 位置要求 |
|---|---|---|---|
| **F1 保险丝** | 5A 快熔，5×20mm 或插片 | 短路保护 | 电池正极入口，**分流之前** |
| **D1 续流二极管** | 1N5822（3A/40V 肖特基）DO-201AD | 电机反峰泄放 | **紧靠泵接线端子** |
| **继电器线圈续流二极管** | 1N4148 或 1N4007 | 线圈反峰 | 紧靠线圈 |

**可选但强烈建议**：
- 继电器触点两端并联 **RC 吸收**（100Ω + 100nF/630V）或 TVS，进一步压电弧
- 泵端子并联 **100nF 陶瓷 + 100µF 电解**

**方案 B（更优，如果愿意改固件）**：
用 **N 沟道 MOSFET 低边开关**（如 IRLZ44N / IRF3205）代替机械继电器。

| | 机械继电器 | MOSFET |
|---|---|---|
| 寿命 | ~10 万次 | 无限 |
| 电弧 | 有 | 无 |
| 噪音 | 咔哒 | 静音 |
| 隔离 | 有 | 无 |

**但注意**：换 MOSFET 后**最短启停时间仍然要保留**（保护泵的阀片，与开关器件无关）。

## 4.2 5V 降压

| 项 | 要求 |
|---|---|
| 输入 | 9 ~ 12.6 V |
| 输出 | 5.0 V ±3% |
| 电流 | 每路 ≥2 A（推荐 5A 余量） |
| 效率 | ≥85%（电池供电，效率直接影响续航） |
| 推荐芯片 | **MP1584EN**（3A，90%）/ **XL4015**（5A）/ **TPS5450** / **MP2315** |
| 不推荐 | LM2596（效率 75%，静态 10mA） |

**每路输入必须**：470µF/25V 电解 + 100nF 陶瓷，**紧靠降压芯片输入脚**。

## 4.3 继电器输入电平（低电平触发）

```
  5V ──[R1 10k]──┬── 继电器模块 IN
                 │
  GPIO5 ─────────┘
```

**R1 是必须的**：模块是低电平触发，ESP32 复位期间 GPIO 高阻，
IN 悬空时可能被干扰误触发。**10k 上拉到 5V 保证不吸合**。

> 如果 PCB 上直接集成继电器驱动电路（不用成品模块），则设计成：
> 光耦输入侧 LED 阳极接 3V3（**不是 5V**），阴极经 1k 电阻接 GPIO。
> 这样 ESP32 输出低电平 = 光耦导通 = 继电器吸合，且天然 3.3V 兼容。

## 4.4 DS18B20 单总线

```
  3V3 ──[R 4.7k]──┬──────────────── GPIO4
                  │
              DS18B20 ×5 全部并联（DQ）
                  │
                 GND
```

| 要点 | 说明 |
|---|---|
| 上拉阻值 | **4.7k，整条总线只允许 1 个** |
| 上拉电压 | **必须 3V3，绝不能接 5V**（ESP32-S3 IO 不是 5V 耐受） |
| 探头数量 | 5 个并联（2 个水温 + 2 个体表 + 1 个环境） |
| 线长 | 探头引线可达 1~2m，**建议用屏蔽线，屏蔽层单端接 GND** |
| 若线很长（>5m） | 上拉改 2.2k |
| 接口 | 建议 3-pin JST-XH 2.54 或 2.54 排针 |

## 4.5 电池电压采样

```
  BAT+ 12.6V ──[R1 100k 1%]──┬── GPIO1（ADC1_CH0）
                             │
                          [R2 18k 1%]  ‖ C 100nF
                             │
                            GND
```

| 要点 | 说明 |
|---|---|
| 分压比 | (100+18)/18 = **6.556**，12.6V → 1.92V |
| 精度 | **1% 金属膜电阻**，否则读数偏 2~3% |
| 滤波 | R2 上并 **100nF**（降低对 ADC 的源阻抗） |
| **必须用 ADC1** | ESP32-S3 的 **ADC2（GPIO11~20）在 WiFi 开启时不可用** |
| 静态耗电 | 12.6V / 118k ≈ 107 µA（可忽略） |

## 4.6 水流传感器接口（可选）

```
  5V ──[R 2.2k]──┬── 传感器 OUT（黄线）
                 │
               [R 10k]
                 │
                 ├──────── GPIO10
                 │
               [R 20k]
                 │
                GND
```

**3 个电阻一个都不能省**。GPIO 上的高电平 = `5×20/(2.2+10+20)` = **3.11V**。
如果省掉 2.2k，高电平只有 2.14V，**低于 ESP32-S3 的 V_IH = 2.475V，识别不到**。

## 4.7 开关量输入

| 信号 | 接法 | 有效电平 |
|---|---|---|
| 液位开关（浮子常开） | 引脚 — 开关 — GND | 低 = 有水 |
| 漏水检测 | 引脚 — 裸铜线A ≈2mm — 裸铜线B — GND | 低 = 遇水 |
| 总电源开关检测 | 引脚 — 开关 — GND | 低 = 闭合 |
| 按键 A / B | 引脚 — 轻触开关 — GND | 低 = 按下 |

**全部用 MCU 内部上拉即可，不需要外部电阻。**
但**建议 PCB 上预留 10k 上拉焊盘**（内部上拉约 45k，噪声环境下偏弱）。

## 4.8 保护与滤波（汇总）

| 位置 | 元件 | 作用 |
|---|---|---|
| 电池入口 | 5A 快熔 | 短路保护 |
| 5V 降压输入 | 470µF + 100nF | 吸收泵启停浪涌 |

# 7. 布局与机械要求

## 7.1 布局

| 要求 | 说明 |
|---|---|
| **功率回路最小** | 电池 → 保险丝 → 继电器 → 泵 的走线尽量短、够粗（≥1.5mm 线宽或铺铜） |
| **单点共地** | 5V_A 地、5V_B 地、3V3 地在电池负极处汇合，不要形成地环路 |
| **单总线远离功率线** | DS18B20 走线不要和泵电源线平行走 |
| **续流二极管紧靠泵端子** | 引线越短越好 |
| **滤波电容紧靠芯片** | 470µF 靠降压芯片输入脚 |
| **继电器远离单总线** | 触点电弧产生宽带干扰 |

## 7.2 机械

| 项 | 要求 |
|---|---|
| 板尺寸 | 建议 **100 × 60 mm** 以内，装进 IP65 防水盒 |
| 安装孔 | **M3 ×4**，四角，孔径 3.2mm |
| 板厚 | 1.6 mm |
| 连接器朝向 | 电源/泵接插件朝一侧，传感器朝另一侧 |
| 三防漆 | **必须**（高湿 + 冷凝水环境） |

## 7.3 环境

| 项 | 值 |
|---|---|
| 温度 | 5 ~ 45 ℃ |
| 湿度 | 高湿，可能凝露 |
| 振动 | 持续（行走），需要防松（螺钉胶 / 卡扣） |
| 防水 | 板子本身不防水，装在防水盒内 |

# 9. 血泪教训（设计时逐条核对）

| # | 教训 | 对应设计措施 |
|---|---|---|
| 1 | **泵从降压板取电，泵和降压板一起烧了** | 泵必须直接从电池经保险丝和继电器取电，走独立的粗铜线 |
| 2 | **没装保险丝** | 保险丝是第一优先级，不能省 |
| 3 | **没装续流二极管** | 泵两端必须反向并联 1N5822，紧靠端子 |
| 4 | **继电器是低电平触发** | IN 必须 10k 上拉到 5V，否则复位期间可能误吸合 |
| 5 | **ESP32 复位期间 GPIO 高阻** | 所有功率控制脚都要外部上拉/下拉定死默认状态 |
| 6 | **板子上有两个 USB 口** | 固件 Serial 走 UART0（CH343），插错口看不到日志。PCB 上直接标注清楚 |
| 7 | **ADC2 在 WiFi 下不可用** | 模拟采样只能放 GPIO1~10 |
| 8 | **OPI PSRAM 占用 GPIO33~37** | 不要引出这些脚 |
| 9 | **3.3V 逻辑驱动 5V 继电器模块** | 高电平只有 3.3V，压差 1.7V，光耦电流偏小。**PCB 上优先做 3.3V 原生驱动电路** |
| 10 | **泵不能 PWM** | 板上**不要**为泵预留 PWM 驱动电路 |

# 10. 建议的板载改进（相比现在的模块搭建）

| 改进 | 收益 |
|---|---|
| **继电器换成板载光耦 + MOSFET 低边开关** | 静音、无触点磨损、体积小。保留续流二极管 |
| **5V 降压集成到板上**（MP1584EN 或 TPS5450） | 省掉两个模块，走线短 |
| **板载 3S 电池电量计**（如 MAX17048） | 比电阻分压准 |
| **电流检测**（INA226 + 0.1Ω 分流） | 能测泵的实际电流，判断堵转/老化 |
| **TVS + 反接保护** | 减少接线事故 |
| **所有传感器用带扣连接器**（JST-XH/PH） | 振动环境下不会松（杜邦线会松） |
| **OLED 直接焊板上** | 不用单独模块 |

# 12. 一句话给画板的朋友

> 这是一块**电池供电、要背在人身上、驱动一台 12V 感性负载电机、还要接 5 路继电器和 5 个温度探头**的
> ESP32-S3 控制板。**电源完整性和保护电路是重点，不是 MCU 部分。**
> 特别是：泵的电流路径只能有 保险丝 + 继电器触点 两个东西，
> 续流二极管和滤波电容必须紧靠负载和芯片，
> 而 3.3V 的 GPIO 不能直接驱动 5V 的继电器模块输入（要高电平上拉或做 3.3V 原生驱动）。
