# 接线总览与电路原理

## 怎么看这些图（图例）

### 图上的圆圈数字是什么

**不是元件编号**，分两种：

| 编号 | 出现在 | 含义 |
|---|---|---|
| 大圆圈 **①②③** | 图 4、图 6 | **分区 / 步骤编号**，纯排版用 |
| **X1-1 ~ X1-8** | 图 6 | **端子位号**：X1 号端子排的第 1 格螺钉 |
| **X2-1 ~ X2-20** | 图 6 | **端子位号**：X2 号端子排的第 1 格螺钉 |

> **X1-1 和 X2-1 是两个完全不同的端子**，别接混。

### 实心小黑点

导线交叉或分支处的**实心小圆点 = 电气连接点**，表示这几根线在这里是连通的。

**没有黑点的交叉 = 两根线只是画面上交叉，实际不相连。** 这是电路图的通用约定。

### 元件位号的正规规则

工程图上真正的元件位号是**字母前缀 + 数字**（GB/T 5094 / IEC 61346）：

| 前缀 | 类别 | 本项目例子 |
|---|---|---|
| X | 端子排 / 连接器 | X1 电源端子排、X2 引脚端子排 |
| R | 电阻 | R1 100k、R2 18k |
| C | 电容 | C1 100nF |
| D | 二极管 | D1 1N5822 续流二极管 |
| K | 继电器 | K1 水泵继电器 |
| M | 电动机 | M1 365 泵 |
| FU | 熔断器 | FU1 5A 保险丝 |
| S | 开关 | S1 肩带开关 |
| BT | 电池 | BT1 3S 锂电组 |
| U | 集成电路 | U1 ESP32-S3 |
| T | 电源模块 | T1 DC-DC #1 |

字母 = 类别，数字 = 同类里的第几个。本项目的图里**没有用元件位号**，
因为元件少（十几个），值都直接标在旁边了（100k、4.7k…）。

# 第一层：电源树

```
3S 锂电池组 (11.1V 标称 / 12.6V 满)
   |
   +-- 5A 快熔保险丝          <- 必须在分流之前
   |
   +-- +12V 母线
         |
         +-- 急停常闭触点 -> 继电器 COM/NO -> 365 泵      (主回路，大电流)
         |
         +-- DC-DC #1 (XL4015E1) -> 5V_A -> 继电器模块 VCC
         |
         +-- DC-DC #2 (MP1584EN) -> 5V_B -> ESP32 + 传感器
                                                   |
                                    开发板自带 LDO -> 3V3 -> 探头

电池负极 ------------------------------ GND 母线（所有模块单点共地）
```

**为什么要两个 DC-DC 分开？**

泵是**有刷电机**，启动瞬间电流是额定的 3~5 倍（0.45A × 4 ≈ **2A**）。
这一下会把 12V 母线拽下去，同时叠加上电机电刷打火产生的高频尖峰。
如果 ESP32 和泵共用一路 5V，这个尖峰就会顺着电源进到单片机里 ——
表现是**跑着跑着自己复位**，而且很难查。分开之后，ESP32 看到的是干净电源。

**为什么从 DC-DC 的 5V 接开发板的 5V 脚，而不是接 3V3 脚？**

开发板上自己有一颗 LDO 负责 5V 到 3.3V。从 5V 脚进，等于复用了它；
直接往 3V3 脚灌 3.3V 会绕过这颗 LDO，而且 USB 一插就和板载 LDO 打架。

# 第二层：主回路（泵怎么被开关）

```
电池+ --[保险丝]--[急停 常闭]--+
                              |
                       继电器 COM
                              |
                         (触点/线圈)
                              |
                       继电器 NO --+-- 泵 +
                                   |
                            [续流二极管]   (反向并联，阴极朝左)
                                   |
                        泵 - ------+-- 电池-
```

## 三个关键点

### 1. 为什么用 NO（常开）而不是 NC

NO 的意思是「线圈不通电时，触点是断开的」。
这样**一旦断电、单片机死机、线掉了，泵自动停**。这是失效安全。
用 NC 的话断电时泵反而在转，背在身上就是事故。

### 2. 为什么把继电器放在正极侧（高边开关）

泵的负极直接回电池负极（也就是公共地），正极走继电器。
另一种做法是负极侧开关（低边），但那样泵的正极永远带电，
在潮湿环境里不如正极受控来得干净。

### 3. 续流二极管 —— 这一条不做会烧继电器

泵是**有刷直流电机，本质是个大电感**。电感里的电流不能突变。
继电器触点断开的瞬间，线圈里的电流被硬生生切断，
根据 U = -L·di/dt，di/dt 极大，于是产生**几百伏的反向电压尖峰**。

后果有两个：

* 触点之间**拉弧**。标称 10A 是**阻性负载**的额定值，感性负载要打对折甚至更多。
  触点会慢慢烧出麻点，用几个月后出现「继电器咔哒响但泵不转」（接触电阻变大）
* 尖峰顺着 12V 母线往回灌，通过 DC-DC 耦合到 3.3V，把 ESP32 打复位

**接法**：二极管**反向并联在泵的两个接线端子上**，
**阴极（有环 / 有银条的那一端）接 +12V 侧**。
正常工作时它反偏截止、不导通；断开瞬间它给电机电流提供一条续流回路，
把尖峰钳在 0.4V（肖特基）左右。

> **接反 = 直接把 12V 电源短路**，会瞬间烧保险丝。装之前用万用表二极管档确认方向。

# 第三层：控制回路（ESP32 怎么让泵转）

```
ESP32 GPIO5 ----> 继电器模块 IN
                   (模块内部: IN -> 光耦 LED -> 光耦三极管 -> 驱动三极管 -> 线圈)
5V_A -----------> 继电器模块 VCC
GND ------------> 继电器模块 GND
```

**继电器模块为什么必须 5V 供电，但 3.3V 信号也能用？**

模块里是「光耦 + 三极管 + 5V 线圈」。线圈是 5V 的，所以 VCC 必须给 5V。
但 IN 引脚后面接的是光耦的 LED，串了限流电阻 ——
3.3V 时电流约 (3.3 - 1.2) / 1000 ≈ 2.1mA，处在光耦的可用区间。
所以 3.3V 信号能驱动。不过不同批次模块限流电阻不一样，**一定要实测**。

**上电瞬间的坑：**

ESP32 复位期间 GPIO 是**高阻输入**（既不输出高也不输出低），
继电器 IN 引脚等于**悬空**。如果模块是高电平触发，IN 悬空可能被拉高，**上电泵就转**。

固件里已经做了防护（先写输出电平、再切成 OUTPUT），
但那只覆盖初始化之后。**从复位到初始化之间还有几百毫秒固件管不到**，
只能靠外部电阻兜住：

* 高电平触发模块：IN 到 GND 接 **10kΩ 下拉**
* 低电平触发模块：IN 到 5V 接 **10kΩ 上拉**

5 个继电器模块，每个 IN 都要加。

# 第四层：传感器

## DS18B20：一根线怎么接 5 个探头

```
3V3 --[4.7k]--+---------------------------- GPIO4
              |
            +-+-+-----+-----+-----+
          [探头1][探头2][探头3][探头4][探头5]      5 个全部并联
            +---+-----+-----+-----+
              |
             GND
```

**单总线（1-Wire）的原理**：一根数据线既传命令又传数据，还兼做供电时序。
总线是**开漏**的，所以必须有一个上拉电阻把线拉高，靠 4.7k 提供。

* 每个 DS18B20 出厂有**全球唯一的 64 位 ROM 地址**，主机先发 ROM 地址再读写，
  所以一条总线上挂多少个都不会串号。
* **整条总线只允许一个上拉电阻。** 5 个探头各带一个 4.7k 就是 940Ω，太低。
* 上拉必须接 **3V3 不是 5V** —— ESP32-S3 的 IO 不是 5V 耐受的，会烧脚。

固件里通过 ROM 地址把探头绑定到角色（map 命令），存进 NVS，掉电不丢。
这样即使探头上电顺序变了也不会串角色。

## 电池电压采样：分压 + ADC

```
BAT+ 12.6V --[R1 100k]--+-- GPIO1 (ADC1_CH0)
                        |
                      [R2 18k]  || 100nF
                        |
                       GND

分压比 = (100 + 18) / 18 = 6.556
12.6V -> 1.92V     9.0V -> 1.37V
```

三个要点：

1. **分压比要算准**。ESP32 引脚绝对最大电压是 VDD + 0.3 = 3.6V。
   12.6V 直接进引脚就是烧。分压后 1.92V，留了足够余量。
2. **必须用 ADC1（GPIO1~10）**。ESP32-S3 有两组 ADC，
   **ADC2（GPIO11~20）在 WiFi 开启时不可用**（被射频占用）。
   虽然现在没开 WiFi，但升级路线里有手机端，先把线接对省得返工。
3. **R2 上并 100nF**。100k / 18k 的并联阻抗约 15k，对 ESP32 的 ADC 偏高，
   采样时会因为内部采样电容充电不足而读数偏低。这颗电容给采样提供本地电荷池。

固件用 analogReadMilliVolts() 而不是 analogRead() —— 前者会读 eFuse 里的
出厂校准值，比 analogRead() * 3.3 / 4095 准得多。

## 水流传感器：5V 方波怎么进 3.3V 的引脚

```
5V --[2.2k]--+-- 传感器 OUT
             |
           [10k] R1
             |
             +-------- GPIO10
             |
           [20k] R2
             |
            GND

GPIO 高电平 = 5 x R2 / (Rpu + R1 + R2) = 5 x 20 / (2.2 + 10 + 20) = 3.11V
```

**那只 2.2k 不能省。** 分压电阻本身就是个负载，会把高电平往下拽：

| 上拉情况 | 送到 GPIO 的高电平 | 结果 |
|---|---|---|
| 自加 2.2k + 10k/20k | 3.11 V | 稳 |
| 只有传感器内部 10k + 10k/20k | 2.50 V | 贴着门限，危险 |
| 只有传感器内部 10k + 10k/15k | 2.14 V | **低于门限，认不出高电平** |

ESP32-S3 的输入高电平门限 V_IH = 0.75 × 3.3 = **2.475V**。
接好后用万用表实测 GPIO10 对 GND 的高电平，**要在 2.8V 以上**。

## 开关量输入：液位 / 急停 / 漏水 / 按键

这四个都用 **MCU 内部上拉**，一端接引脚、一端接 GND：

| 信号 | 接法 | 有效状态 |
|---|---|---|
| 液位开关（浮子，常开 NO） | 引脚 — 开关 — GND | 低 = 有水 |
| 漏水检测（两根裸铜线） | 引脚 — 裸铜线A — 约2mm间隙 — 裸铜线B — GND | 低 = 遇水 |
| 急停按钮（**常闭 NC**） | 引脚 — 按钮 — GND | **高 = 按下或线断** |
| 按键 A / B | 引脚 — 轻触开关 — GND | 低 = 按下 |

**急停为什么用常闭？**

不按时触点闭合到 GND，引脚读低；按下时断开，被上拉拉高。
这样**「按下」和「线断了」是同一种结果** —— 失效安全。
常开的话线断了没人知道，急停就形同虚设。

软件急停依赖单片机活着。**强烈建议把按钮的另一组触点串在泵的 12V 硬回路里**，
这样即使单片机死机，按下去也能物理切断。

# 第五层：这几层怎么配合工作

```
DS18B20 每 ~2 秒采一次 5 个温度
        |
        v
PumpController 每 500ms 判决一次：

   1) 安全联锁（可以打断最短运行时间，立即停泵）
      漏水 / 急停 / 液位低 / 电池电压低 / 水温过低 / 读数全废
        |
   2) 最短运行 20s、最短停机 30s（保护触点与泵阀片）
        |
   3) 需求判定：体表温度 >= 目标+回差/2 -> 开泵
                体表温度 <= 目标-回差/2 -> 停泵
        |
        v
GPIO5 -> 继电器 -> 泵
```

**为什么不能 PWM 调速？**

有刷电机的换向器和电刷在 PWM 下会剧烈打火、发热、噪音大；
隔膜泵在低速下流量急剧下降、阀片拍打异常。
所以只能整段开、整段关，靠**时间比例**模拟调速 ——
一个开关周期是几十秒到几分钟，远大于电机的热时间常数，
电机每次都按额定转速工作，没有任何副作用。

# 上电顺序（别跳步）

1. **不接泵**，只上 ESP32 → 看启动横幅、确认 16MB flash / 8MB PSRAM
2. 接 1 个 DS18B20 + 4.7k → `scan`，丢进冰水混合物校准到 0°C
3. 接齐 5 个 → `map` 绑定角色 → `save`
4. **只测继电器模块（不接泵）** → `aux 1 on` / `aux 1 off`
   按住 RST 复位 20 次，确认泵不会误抽 → 决定要不要加 10k
5. 接泵（先不接水，每次通电 ≤3 秒）→ 测干扰，看串口丢不丢字符
6. 加水循环 30 分钟 → 测密封和渗漏
7. 用水杯模拟温度做控温闭环测试
8. 最后才上身

完整验收标准见 `docs/BRINGUP.md`。
