# 密封、冷凝与热工审查

> 结论先说：**你的密封做法是对的**（穿板宝塔头 + 内外硅胶圈 + 卡箍 + 卡箍），
> 但有一个认知偏差需要纠正：
> 「把冰袋封在 PET 罐里就不会有冷凝水」—— 不完全对。冷凝水不会消失，
> 它只是**从冰袋表面转移到了罐外壁和 10 米长的低温软管外壁**。
> 而软管那一部分才是大头。

---

## 一、冷凝水：真正的问题在管子，不在罐子

冷量最终一定要和空气接触才能漏出去，有低温表面就一定有冷凝水。

| 部位 | 温度 | 面积 | 冷凝情况 |
|---|---|---|---|
| 冰袋表面 | -5 ~ 0 度 | 大 | 已经封在罐里，解决 |
| **PET 罐外壁** | 5 ~ 10 度 | 约 0.06 m2 | 会结露，顺着罐壁往下淌 |
| **10m 软管的暴露段** | 8 ~ 15 度 | 约 0.20 m2 | **主要问题** —— 6~7 米长的冷管子就是一台除湿机 |
| 软管的贴身段 | 25 ~ 30 度 | 约 0.15 m2 | 管壁被皮肤加热，基本不结露 |

**做法**：

1. **暴露段软管全部套保温海绵管**（空调铜管用的那种黑色闭孔橡塑发泡管，
   **内径 12mm**）。注意：8x11 管的意思是内径 8 / 外径 **11mm**，
   所以保温管内径必须 >= 12mm 才套得进去。这一步同时解决两件事：隔断结露 + 减少冷损，
   而冷损比结露更致命（见第四节）。
2. **PET 罐外面套保温套**（潜水料 / 珍珠棉 / 保温袋），再把罐子放进背包的**防水内衬**里，
   内衬底部留一个**朝下的排水小口**，万一渗水不会泡到电池。
3. **贴身段软管在速干衣下面**，那一段的少量冷凝水直接被衣服吸收。
4. 背包里不要放怕水的东西。电池盒单独做防水。

## 二、PET 罐开孔与密封（你的方案基本正确，补几个细节）

你说的是「穿板宝塔头（外径 8mm，螺纹 M12）× 5 + 硅胶密封圈 × 10 + 304 卡箍 × 10」，
**10 个圈 = 5 个接头 × 内外各 1 个，数量正好，这个搭配是对的**。下面是执行细节：

### 开孔

* **PET 又脆又薄，直接钻孔必裂**。步骤：
  1. 用 3mm 钻头打引导孔（防止钻头跑偏）；
  2. 换 **12mm 钻头**扩孔。穿板接头自带螺母 + 密封圈，**不需要攻丝** ——
     攻 M12 螺纹反而会把 PET 涨裂；
  3. **低转速 + 滴几滴水冷却**。转速高了 PET 会熔化拉丝，孔口变成一圈毛刺，密封圈压不实。
* 孔位要求：**离罐壁边缘 >= 8mm，离罐底 >= 10mm**。
* 5 个孔**分散布置**，不要全挤在同一侧 —— 受力不均会让薄壁罐变形，密封圈跟着失效。

### 密封圈装配顺序（内外各一个）

```
    罐外              罐壁            罐内
  [宝塔头法兰] [硅胶圈] │PET│ [硅胶圈] [螺母]
```

* 拧紧力度：**手拧到刚好吃住，再紧 1/4 圈**。用扳手暴力拧 = PET 开裂。
* **PET 会蠕变**：装好后 24 小时，以及第一次跑循环之后，**再复紧一次**。
  很多人第一次漏水都是因为漏了这一步。

### 软管与卡箍

* 软管要**插到宝塔头根部**，把所有台阶都淹没 —— 宝塔头的每一道凸起都是一道密封；
* 卡箍卡在**凸起之后**（靠近法兰那一侧的第一道台阶后方），**不要卡在凸起上面**，
  卡在凸起上会让软管鼓包，密封反而更差；
* 304 卡箍拧到「软管表面微微凹陷」就够，拧过头会切伤软管。

### 建议从盖子出管，而不是从侧壁

* 广口盒的**盖子平整、厚实、好开孔、好密封**，而且侧壁出管在背包里
  **容易被压弯折死**（流量归零，泵空转）。
* 代价：卡扣盖本身的密封靠一圈硅胶条，不算可靠。
  **内侧再贴一圈自粘硅胶密封条**，并且盖子周围用一根魔术贴绑带箍紧。

### 罐内必须留 15~20% 空气，并且强烈建议加透气口

* 这是**闭式循环**（出水和回水都在同一个罐上），净流量为零，理论上不会产生持续负压。
* **但是**：① 水温变化导致罐内空气热胀冷缩；② 泵启动 / 停止瞬间的压力波动；
  ③ 万一回水管有轻微渗漏进了空气。
  一个**完全刚性密封**的薄壁 PET 罐，在泵抽水时会被**吸瘪**。
* **做法**：在盖子上装一个 **防水透气阀**（Gore 阀 / 疏水透气膜），
  或者一根 30mm 短管 + 一小团棉花或海绵塞（防溅水）。

## ★ 软管被泵吸瘪（贴身段尤其明显）—— 排查与根治

**现象**：贴身段的软管在工作时被吸成扁的，流量掉下去，泵声音变尖（憋压）。

**先明白一件事：瘪 = 管子承受的负压 > 管壁的抗压能力。**
所以只有两条路：**要么别让这段管子处在负压侧，要么让管子抗得住。**
按性价比从高到低：

### ① 罐子必须透气（不花钱，先查这个）

如果罐子被完全密封，泵一抽就把罐内抽成负压 —— 那时**整个回路从头到尾都是负压**，
再硬的管子也可能瘪，而且泵会气蚀、流量暴跌。**先拧开盖子或者装透气阀试一次**，
如果瘪立刻减轻，就是这个问题。

### ② ★ 把泵挪到体表回路的上游：改成「推」，不要「吸」（根本解法，不花钱）

```
现在（吸）：罐 → 体表管 → 泵 → 罐      体表管全程负压  → 瘪
改成（推）：罐 → 泵 → 体表管 → 罐      体表管全程正压  → 不可能瘪
```

365 隔膜泵自吸能力够，两种接法都能工作，但**「推」对软管友好得多**——
正压只会让管子鼓，不会让它瘪。这就是为什么家用净水器、鱼缸过滤都是「泵在后、
负载在前」。

**顺带的好处**：最冷的那段水（刚从冰袋出来）直接进体表管，冷量损失更小。
**代价**：接头漏水会往衣服里喷水（负压时反而是往管内吸空气，更安全），
所以接头一定要卡箍拧紧。

### ③ 负压段别用硅胶管

| 管材 | 抗负压 | 说明 |
|---|---|---|
| PU / PE / PVC 硬管 | 强 | 8×11 那种，负压段随便用 |
| 硅胶管 6×8（壁厚 1mm） | **极弱** | 手感软，一吸就瘪 —— **只能用在泵的出口侧** |

贴身段想用硅胶图舒服，可以，但**必须放在泵的下游（正压侧）**。

### ④ 防瘪弹簧 / 螺旋增强管

* 把一根不锈钢丝绕成螺旋（外径略小于管内径）塞进软管里，就是最简单的防瘪内衬；
* 或者直接买**带螺旋筋的防瘪吸水管**（养鱼 / 洗车用的那种透明螺旋管）。
* 缺点：内壁有筋，阻力上升，流量会降一点。

### ⑤ 降低沿程阻力（负压 ∝ 阻力）

* **死折是最凶的**：一个 90° 死折的局部阻力相当于好几米直管，那一段一定最先瘪。
  所有拐弯半径做到 **> 5 倍管径**（8mm 管 -> 半径 > 40mm）。
* 负压段尽量短，别用比 8mm 更细的过渡接头（那等于一个限流孔）。
* 贴身段的盘管别盘得太密 —— 每一圈都是一个弯。

### ⑥ 排查手法

1. 关掉泵，用手把整条管路摸一遍，先找死折和压扁的地方；
2. 开泵，从泵的入口往回摸，**最先瘪的那一段就是阻力最大的地方**；
3. ⚠ **管子瘪着的时候泵处在憋压状态，长时间会把阀片顶坏 / 电机过热熔化** ——
   发现瘪立刻停机处理，别让它硬抽。

## ★ 贴身那 1 米软管怎么固定才不会被压瘪

**关键认知：圆截面的软管天生怕侧向点压力。** 只有两条思路 ——
**要么给它做「外骨骼」把点压变成面压，要么把这一段挪出负压侧。**

### 方案 D（零成本，最优先）：把这一米挪到泵的出口侧

正压侧的管子被压只会**鼓**，不会瘪。如果贴身段现在在泵的入口侧，
它天生就是「被吸瘪」的命 —— 先改管路，再谈固定。

```
罐 → 泵 → [这 1 米贴身管，正压] → 回罐        ← 就改成这样
```

### 方案 A（最推荐，DIY 一下午）：嵌进开槽泡棉，做成一块换热垫

```
俯视（贴皮肤的那一面）：
  ┌──────────────────────────────┐
  │  EVA 泡棉 5mm                 │
  │   ████████████████████████   │  <- 蛇形槽，宽 = 管外径 8mm
  │   ██ 硅胶管嵌在槽里 ██████   │     槽深 ≈ 管径的 2/3
  │  ──────────────────────────  │
  └──────────────────────────────┘
     ↑ 管子露出 1/3 直接贴皮肤换热，2/3 被泡棉保护
```

* 材料：5mm 厚 **EVA 泡棉**（瑜伽垫 / 鼠标垫 / 儿童地垫都行），裁成胸口或后背的形状；
* 用美工刀挖一条**蛇形槽**，槽宽 = 硅胶管外径（8mm），槽深约 5~6mm；
* 把硅胶管压进槽里 —— **垂直方向的所有压力都由泡棉承担**，管子被"包"住，压不瘪；
* 露出的 1/3 管壁照常贴皮肤换热，泡棉的隔热影响很小；
* 边缘缝两条宽松紧带 / 魔术贴，固定在速干衣外面。

### 方案 B：螺旋弹簧内衬（唯一能让软管本身抗瘪的办法）

* 不锈钢丝 **Φ0.8mm**，绕成螺旋，**外径约 5mm**（硅胶管内径 6mm，留 1mm 余量才能塞进去），
  螺距 3~5mm，整段穿进去；
* 或者直接买**「防瘪弹簧管」/「螺旋增强硅胶管」**；
* 代价：沿程阻力上升，流量降 10~20%。

### 方案 C：外套塑料波纹穿线管

硅胶管穿进**内径 8~10mm 的塑料波纹管**里。波纹管的环向刚性很高，压不瘪、还能弯。
代价：外径变粗到 14~16mm，贴身变硬变硌 —— 只适合走路，不适合背着靠。

### 方案 E（正确答案，但要花钱）：换成扁通道冷敷垫

圆管和皮肤只有**一条线**接触，换热效率本来就差。
医用冷敷垫那种**扁平多通道 PVC 垫**天生抗压（压力方向垂直于通道宽面），
而且换热面积大 4~5 倍。买不到就自己用两片 PVC/TPU 膜热合成蛇形通道。

### 方案 F：走位，避开所有受压点

* ✗ 别走**肩带正下方**、别走**脊柱正中**、别走**腰带位置**；
* ✓ 走**肩胛骨内侧的凹处**、贴着**肋骨**走；
* 用**宽扁的松紧带**分散固定，**别用细尼龙扎带勒** —— 细扎带本身就是一个压瘪点。

### 顺带说管材

6×8 硅胶管的**壁厚只有 1mm**，是抗瘪能力最差的规格。
如果一定要用软管贴身，选 **6×10（壁厚 2mm）** 会好很多，代价是粗一点、贴合差一点。

## ★★ 让泵不会因为被压瘪而死（三道防线，比机械固定更紧急）

你已经烧掉 2 台泵了。机械固定是「尽量不发生」，下面三道是「发生了也不会烧」。

| 防线 | 实现 | 代价 | 说明 |
|---|---|---|---|
| ① 水流传感器 | 装 **YF-S401** 到 GPIO10，`ENABLE_FLOW_SENSOR` 改 1 | 约 10 元 | **最灵**，能抓住「管子刚好被压瘪」那一瞬间 |
| ② 连续运行上限 | 串口 `maxrun <分钟>`，默认 10 分钟 | 0 元 | 不用传感器，兜底 |
| ③ **热保护开关** | **KSD9700 常闭 70°C** 串在泵的电源线上 | 几毛钱 | **硬件保护，最可靠** |

**防线③ 强烈建议装上。** 它是双金属片机械开关，泵壳一到 70°C 直接物理断电 ——
不管固件怎么错、MCU 怎么死机、MOS 怎么击穿，它都会断。这是最后一道保险，
而且只要有它在，前两道即使失效也不会烧泵。串接位置：

```
电池+ → 保险丝 → 继电器 COM → NO → [KSD9700 70°C] → 泵+ → 泵− → 电池−
                                     ↑ 紧贴泵壳，用导热硅脂+扎带固定
```

固件侧已实现（`controller.cpp` `updateRunGuard()`）：

* 判据①（需水流传感器）：泵开着但 `FLOW_CHECK_MS`(15s) 内流量 < `FLOW_MIN_LPM`(0.2 L/min)；
* 判据②：`m_curOnMs > maxRunMs`；
* 触发后：立即停泵 → 强制休息 `grest`（默认 60s）→ **自动重试**，形成「试-停-试」循环；
* `status` 的 `reason` 行会直接说明原因，例如：
  `泵保护停机：泵在转但水流传感器读不到水（管瘪 / 堵塞 / 没水）（42 秒后自动重试）`；
* `clear` 可立即解除，`maxrun 0` 可关闭（不建议）。

* **吸水管**（去泵的那根）伸到罐底，但**离底 5~10mm**，管口剪成斜口或套一个不锈钢网 / 海绵粗滤，
  防止吸到底部碎屑和冰袋碎渣。**这一条直接决定泵会不会堵。**
* **回水管**（从身上回来的）伸到罐内**液面附近**，不要插到底 ——
  避免回水直冲罐底搅动沉淀，也避免停机时虹吸倒流。

## 三、泵的安装位置

* 泵装在罐外，**进水口低于罐内最低液位**。利用重力灌注。
  365 泵虽然标称自吸，但自吸高度超过 0.3~0.5m 后流量会明显下降，而且容易气蚀、噪音大。
* 进水口管路**尽量短、少弯头**，中间不要用比 8mm 更细的过渡接头（那就是个限流孔）。
* **绝对不能干转**。隔膜泵干转几分钟，阀片和膜片就废了。
  第一次使用必须先灌引水（从回水管往罐里倒水，或者把回水管拔下来看有没有水出来）。
  固件里的 `DRY_RUN` 报警就是给这个兜底的。
* 泵和罐、泵和背包之间**垫一层减震海绵**。隔膜泵的振动在背包里会被放大成嗡嗡声，
  而且长期振动会磨破软管。

## 四、热工估算：这套系统到底能撑多久

这部分建议认真看一遍，因为它决定了你的预期是否合理。

### 10 米软管的代价

8mm 内径、10 米长：

```
管内容积 = 3.1416 x (4mm)^2 x 10000mm = 502,655 mm3 约等于 0.50 升
```

**你的水箱才 500ml —— 管路里的水和罐里的水一样多。** 后果：

* 泵要先把这 0.5L 的水推完一圈，才有冷量回到罐里，系统响应变慢；
* 这 0.5L 水本身也是热容，需要额外的冰去冷却它。

沿程阻力其实**没有想象中那么糟**：10 米 8mm 管在 1.5 L/min 下压降约 **6~7 kPa（0.06~0.07 bar）**，
对 365 泵（最大压力 0.2~0.5 MPa）来说只掉 10~20% 流量。**真正的代价是冷损，见下条。**

### 保温 vs 不保温：真实数字

按圆柱保温层算（管内水温 10C、环境 30C），每米冷损：

| 保温层厚度 | 成品外径 | 每米冷损 | 相比裸管 | 外表面温度 | 会不会结露 |
|---|---|---|---|---|---|
| 裸管 | 11 mm | **9.0 W/m** | — | 10 C | **必结露** |
| 9 mm | 30 mm | 6.2 W/m | -31% | 25.0 C | 临界（露点约 26 C） |
| **13 mm** | 38 mm | **5.5 W/m** | -39% | 26.6 C | 基本不结 |
| 20 mm | 52 mm | 4.6 W/m | -48% | 27.9 C | 不结 |

> 这里有个反直觉的地方：保温层加厚之后**外径也变大了**，
> 外表面积从 0.035 m2/m 涨到 0.119 m2/m（13mm 时），
> 加上辐射散热，**实际收益比直觉小**。9mm 只降 31%，20mm 才降 48%。
> 别指望套一层保温就能把冷损干掉 90%。

**更关键的是：裁短软管比套保温有效得多。**

| 配置 | 暴露段 | 软管冷损 | 罐壁冷损 | 总冷损 | 预计续航 | 其中有效冷却 |
|---|---|---|---|---|---|---|
| 10 m 管，不保温 | 6.5 m | 58 W | 12 W | **70 W** | 32 分钟 | 12 分钟当量 |
| 10 m 管 + 13mm 保温 | 6.5 m | 36 W | 2 W | 37 W | 46 分钟 | 24 分钟当量 |
| 5 m 管，不保温 | 2 m | 18 W | 12 W | 30 W | 51 分钟 | 29 分钟当量 |
| **5 m 管 + 13mm 保温** | 2 m | 11 W | 2 W | **13 W** | **67 分钟** | **51 分钟当量** |

假设：冰量 500 g（214 kJ）、体表吸热 40 W。

**结论**：

* 只套保温（管子还是 10m）：**有效冷却翻倍**（12 -> 24 分钟当量）
* 只裁管子（5m，不保温）：有效冷却 12 -> 29 分钟当量，**比只套保温还强**
* **两个一起做：有效冷却提升 4 倍以上**（12 -> 51 分钟当量）

所以正确顺序是：**先裁管子，再套保温。** 保温是雪中送炭之后再加的棉袄，
不是单独就能救命的。

### 但保温管还有一个不可替代的作用：防结露

这一条和冷损无关，是**独立且确凿**的理由：

* 裸露冷管外壁约 10 C，而 30 C / 80%RH 的露点约 **26.2 C**
  （湿度 90% 时露点升到 28.2 C）
* 温差 16 C，必然大量结露，水顺着管子滴到身上和背包里
* 套 13mm 保温后外表面升到 **26.6 C**，刚好压住露点

**你当初把冰袋封进 PET 罐就是为了防这个，但冷凝水只是转移到了罐外壁和管子外壁。**
想彻底解决，光靠保温不够，要三件套一起上：

1. 暴露段套 13mm 保温管
2. 罐子套保温套，放进背包的**防水内衬**里
3. 内衬底部留一个**朝下的排水小口**

**省钱省事的做法**：贴身那一段软管**根本不用保温** —— 它贴着皮肤，本来就是要换热的。
只有「从背包出来到衣服里」那一小段是暴露的。
把罐子和泵放在**背包最下层**，软管从背包底部直接穿进衣服，
暴露段可以压到 **1~1.5 m**，保温管只买 1.5 m 就够了，又省钱又不臃肿。

### 冰量能撑多久

按你现有的配置（500ml 水 + 自吸水冰袋）估算，假设有效冰量 **500g**：

```
融化潜热          334 J/g x 500 g          = 167 kJ
冰从 -5 度升到 0 度  2.05 J/(g·K) x 500 x 5  =   5 kJ
融水从 0 度升到 20 度 4.18 J/(g·K) x 500 x 20 =  42 kJ
                                    合计  约 214 kJ
```

* 静息状态（人体产热约 100W，系统实际带走约 40W）：
  **214 kJ / 40 W 约等于 5350 秒 约等于 89 分钟**
* 活动状态（产热 200~400W，系统带走 60W 左右，且冰消耗更快）：
  **大约 30~45 分钟**

**结论：这是一套「延缓升温 / 局部降温」装备，不是「全身空调」。**
要延长续航，按性价比排序：

1. **加保温**（效果最猛）—— 续航 x1.5~2
2. **加大水量**：100x150mm 的 PET 盒大概能装 1~1.5L，用 2~3 个盒子串联；
   水的显热虽然不如冰，但能显著延长最后那 20 分钟
3. **加冰量**：冰袋从 500g 加到 1kg —— 续航线性延长
4. **缩短软管**：从 10m 裁到 4~5m，减少管内容积和暴露面积

### 走管与人体安全

* **软管不能直接贴皮肤**（你已经知道）。再补充一点：8x11 的 PVC 管**偏硬**，
  长时间压在背上会形成压痕和压迫点。建议贴身段换 **6x8 的硅胶管**
  （更软、更细、更贴合），或者在外面包一层薄棉布做成垫片。
* **冷损伤**：水温低于 12 度左右、长时间大面积接触皮肤，有冷性荨麻疹和冻伤风险。
  所以固件里设了 `wmin`（默认 8 度停泵）。**建议实测后调到 10~12 度。**
* **走管避开**腋下、腹股沟、颈前这些大血管浅表区 —— 在这些地方快速降温会引起
  强烈不适甚至寒战（寒战反而会让产热暴增，适得其反）。
* **单次连续使用不超过 60 分钟**，中间让皮肤回暖。

## 五、密封测试怎么做（做完了再上身）

### 静态保压测试

1. 罐里装满水，**把所有接头拧紧**，堵住出水口和回水口。
2. 用手捏软管加压（或者用泵短时憋压 **不超过 10 秒** —— 憋太久会损坏泵的阀片）。
3. 罐子下面垫**干燥的纸巾**，静置 **30 分钟**。
4. 纸巾有任何湿痕 → 找到那个接头，复紧；还漏就换密封圈。

### 动态循环测试

1. 泵接上，装满水，让它**连续循环 30 分钟**。
2. 观察所有接头、罐底、泵的进出水口。
3. 中途把罐子**倒过来放 5 分钟**（模拟背包晃动），继续观察。
4. 注意听泵的声音：有明显咕噜咕噜的气泡声 → 进水口漏气，检查卡箍和宝塔头。

### 冷凝测试

1. 罐里放冰袋，泵循环起来，**在湿度大的环境**（比如刚洗完澡的浴室）放 20 分钟。
2. 看罐外壁和软管外壁有没有水珠往下滴。
3. 有 → 按第一节加保温棉和保温套。
