# 防折螺旋护套（3D 打印件）

## 它解决什么问题

6×8 硅胶管**一折就瘪，瘪了以后即使泵有压力也撑不开**，结果是泵憋压 → 电机过热 → 烧泵。

这个护套套在硅胶管外面，一次解决两件事：

1. **径向撑住** —— 1.7mm 的硬壳把管壁撑住，背包压、手捏、绑带勒都不会瘪；
2. **限制弯曲半径** —— 弯曲时螺旋缝在**内侧闭合并顶死**，管子再也弯不到会打死折的角度。

```
        直的                      弯的
   ┌───────────┐            ╭───────────╮
   │ ~~~~~~~~~ │           ╱ ~~~~~~~~~ ╲
   │  硅胶管    │          │  硅胶管     │
   │ ~~~~~~~~~ │           ╲ ~~~~~~~~~ ╱
   └───────────┘            ╰───────────╯
     螺旋缝          外侧：缝张开     内侧：缝闭合 -> 顶死，不能继续弯
```

## 文件

| 文件 | 缝宽 | 长度 | 最小弯曲半径 Rmin | 缝处材料应变 | 说明 |
|---|---|---|---|---|---|
| `sleeve_A_flex.stl`  | 2.0 mm | 150 mm | **24 mm** | 4.7% | 最软最好盘，但缝处应变偏大 |
| `sleeve_B_mid.stl`   | 1.5 mm | 150 mm | **32 mm** | 3.3% | ★ **推荐**，两端都合适 |
| `sleeve_C_rigid.stl` | 1.0 mm | 150 mm | **48 mm** | 2.0% | 最硬最抗瘪，但只能缓弯 |
| `sleeve_A_short.stl` | 2.0 mm | 60 mm  | 24 mm | 4.7% | 先打这个试手感 |

**Rmin 和材料应变是互斥的**：缝越宽，能弯得越急，但缝两侧的材料被拉伸得越厉害、越容易疲劳。
`Rmin × 应变 ≈ 0.85 mm` 是这套几何的硬约束，改不了。

* 想更耐弯 → 选 A（缝 2.0），代价是缝处应变 4.7%，PETG 长期反复弯可能疲劳开裂；
* 想更耐久 → 选 C（缝 1.0），代价是最小弯曲半径 48mm，盘不紧。

**推荐从 `sleeve_B_mid` 开始**，或者先打一段 `sleeve_A_short`（60mm）试手感。

## 打印参数

| 项 | 建议 |
|---|---|
| 材料 | **PETG**（必须）。PLA 太脆，反复弯会裂；TPU 太软撑不住 |
| 摆放 | **竖着立起来打**（螺旋轴沿 Z），不需要任何支撑 |
| 层高 | 0.2 mm |
| 壁厚 | 2 圈（0.8mm）就够，别开填充 |
| 底边 | **加 brim**。150mm 高、12mm 粗的细高件接触面很小，容易倒 |
| 速度 | 降到 60%，细高件高速打会晃 |
| 后处理 | 打完用手弯一弯，把螺旋缝里可能粘连的地方掰开 |

## 怎么用

1. **先把护套套到硅胶管上，再去接两端的宝塔头** —— 螺旋缝是连续的一条，管子没法从侧面塞进去。
   如果管子已经接好了：用斜口钳沿螺旋缝剪开一段，掰开套上去，再用扎带箍一下。
2. 1 米管子约需要 `1000 / 150 ≈ 7` 段。
3. 分段之间**对接**即可，接口缠一圈电工胶带或套一小段热缩管。
4. 套好以后管子可以盘成 R ≥ 对应 Rmin 的蛇形。**弯到顶死时会明显感觉“到头了”** —— 那就是限位在起作用，别硬掰。
5. 固定到身上：护套外径 12mm，用尼龙扎带或松紧带环固定 —— **环要比管子松 1~2mm，别勒死**。

## 重新生成 / 改参数

```
# 改 make_sleeve.py 里 VARIANTS 表的参数后：
.venv\Scripts\python.exe .\projects\body-cooler\cad\make_sleeve.py

# 渲染预览（Blender headless）
& 'E:\Blender\blender.exe' -b --factory-startup -P .\projects\body-cooler\cad\render_preview.py -- `
    .\projects\body-cooler\cad\sleeve_B_mid.stl .\projects\body-cooler\cad\preview.png iso
```

几何全部由 `helix_sleeve()` 一个函数算出，纯 Python + 手写二进制 STL，**不依赖任何第三方库**。
核心参数：`r_in` `r_out` `slit` `pitch` `length` `ang_n` `step`。

## 生成方式说明

本机装的是 Blender 5.2.1（E:\Blender）。MCP 服务没法在会话中途热加载进工具表，
所以这里用的是 Blender 自带的 headless Python API：

```
blender.exe --background --factory-startup --python <脚本> -- <参数>
```

它比 MCP 更适合这件事 —— 参数化、可批量化、可版本控制，而且渲染预览和网格检查都能自动跑。
