# 四、关键设计决策（已定，别再纠结）

| 决策 | 原因 |
|---|---|
| **水泵只能整段启停，不能 PWM** | 有刷电机换向器在 PWM 下剧烈打火；隔膜泵低速阀片拍打异常 |
| **用时间比例模拟调速** | 周期几十秒到几分钟，远大于电机热时间常数 |
| **继电器用 NO 不用 NC** | 断电/死机/线断时泵自动停，失效安全 |
| **续流二极管必须有** | 感性负载反峰几百伏，会烧触点 + 打复位 ESP32 |
| **两路 DC-DC 分开** | 泵启动瞬间 2A，干扰会顺着电源进单片机 |
| **TEC 方案放弃** | 5 片 TEC1-12712 要 50A / 600W，热端 1300W 排不掉，电池撑 10 分钟 |
| **DS18B20 用 ROM 地址绑角色** | 总线上电顺序会变，按序号绑会串角色 |
| **整条单总线只加 1 个 4.7k 上拉** | 5 个模块各带一个就是 940Ω，太低 |
| **端子排方案放弃，改单个端子 + 直连** | 端子排是多余的一层接点 |
