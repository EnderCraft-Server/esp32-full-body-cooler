## 二、按功能分组

### 输出（继电器 / 指示灯 / 蜂鸣器）

| GPIO | 功能 | 默认电平（REL_ACTIVE_HIGH=1） |
|---|---|---|
| 5 | 继电器1 → 365 水泵 | LOW = 泵停 |
| 6 | 继电器2 → 备用 | LOW |
| 7 | 继电器3 → 备用 | LOW |
| 15 | 继电器4 → 备用 | LOW |
| 16 | 继电器5 → 备用 / 总闸 | LOW |
| 17 | 蜂鸣器 | LOW |
| 48 | WS2812 状态灯 | 灭 |

固件里 `PumpController::begin()` 的顺序是**先写电平、再切成 OUTPUT**，
避免 `pinMode` 和 `digitalWrite` 之间那几微秒继电器误触发。
但复位到 `begin()` 之间固件管不到，所以 IN 引脚上的 10k 上拉/下拉是必须的。

### 输入（数字开关量）

| GPIO | 功能 | 上拉 | 有效电平 |
|---|---|---|---|
| 11 | 液位开关（浮子簧片） | 内部上拉 | 低 = 有水（`LEVEL_ACTIVE_LOW`） |
| 18 | 漏水检测（两根裸铜线） | 内部上拉 | 低 = 遇水（`LEAK_ACTIVE_LOW`） |
| 21 | 急停按钮（常闭 NC） | 内部上拉 | **高 = 按下或线断**（`ESTOP_ACTIVE_HIGH`） |
| 38 / 39 | 按键 A / B | 内部上拉 | 低 = 按下 |
| 10 | 水流传感器（霍尔脉冲） | 外部 10k 分压 | 下降沿计数 |

> GPIO21 原本留给急停按钮。现在**不需要独立的急停按钮**，
> 只要有一个**不解背包就够得着的总电源开关**（建议装在肩带上的自锁翘板开关）。
> 想用软件读开关状态也行；不用就把 `ENABLE_ESTOP` 保持 0，引脚空着。

### 输入（模拟 / ADC）

| GPIO | ADC 通道 | 用途 | 分压比 |
|---|---|---|---|
| 1 | ADC1_CH0 | 电池电压 | 6.556 : 1（100k / 18k） |
| 2 | ADC1_CH1 | 备用（泵电流 / 压力） | 待定 |

### 通信

| GPIO | 功能 |
|---|---|
| 8 / 9 | I2C SDA / SCL（OLED、INA219、SHT30） |
| 43 / 44 | UART0 → 板载 CH343 → 电脑 COM 口 |
| 19 / 20 | 预留：ESP32-S3 原生 USB（当前不用） |

## 三、为什么这些脚不能用

| GPIO | 原因 | 接上去会怎样 |
|---|---|---|
| 0 | strapping：上电电平决定 boot 模式 | 接负载 -> 烧录失败 / 启动异常 |
| 3 | strapping：JTAG 源选择 | 同上，且默认电压是 1.5V |
| 45 | strapping：VDD_SPI 电压选择 | 上电拉低 -> flash 供电错误，直接不启动 |
| 46 | strapping：启动模式 | 同上 |
| 19 / 20 | 原生 USB D- / D+ | 接负载 -> USB 通信异常 |
| 26 ~ 32 | 内部 SPI0/1，接 flash | **直接不启动** |
| 33 ~ 37 | OPI PSRAM（N16R8 才有） | 丢 8MB PSRAM，或直接不启动 |
| 43 / 44 | UART0 | 丢掉串口控制台（板载 CH343 就靠它） |

## 四、ADC 的两个大坑

### 1. ESP32-S3 有两组 ADC，WiFi 开启时 ADC2 不能用

| 组 | 引脚 | 备注 |
|---|---|---|
| **ADC1** | GPIO 1 ~ 10（CH0 ~ CH9） | 任何情况下都能用 |
| ADC2 | GPIO 11 ~ 20 | **WiFi 一开就不可用**（被射频占用） |

所以电池采样和泵电流采样**必须落在 GPIO1 ~ 10 上**。虽然现在没开 WiFi，
但升级路线里有手机端曲线这一项，先把线接对省得以后返工。

### 2. 源阻抗不能高

100k / 18k 分压的并联阻抗是 100k × 18k / 118k ≈ 15.3k，对 ESP32 的 ADC 来说偏高，
采样时会因为内部采样电容充电不足而读数偏低。两个办法，一起用最稳：

1. 在 R2 两端并一只 **100nF** 陶瓷电容 —— 给采样电容提供一个本地电荷池；
2. 用 `analogReadMilliVolts()` 而不是 `analogRead()` —— 它会读 eFuse 里的出厂校准值，
   比 `analogRead() * 3.3 / 4095` 准得多（固件里已经这么写了）。

顺带把衰减设成 11dB（`ADC_11db`），量程约 0 ~ 2.5V 线性段。
12.6V 经 6.556:1 分压是 1.92V，留了足够余量。

## 五、rev2 新增部分的接线图

### 电池电压（GPIO1）

```
  电池 BAT+ 12.6V
       |
     [R1 100k]
       |
       +------ GPIO1 (ADC1_CH0)
       |
     [R2 18k]      || 100nF
       |           ||
      GND         GND

  分压比 = (100 + 18) / 18 = 6.556
  12.6V -> 1.92V   9.0V -> 1.37V   0V -> 0V
```

静态耗电 12.6V / 118k ≈ 107uA，对 9Ah 的电池组可以忽略（约 0.001% / 小时）。

### 水流传感器（GPIO10）

```
  5V --- 传感器 VCC(红)
  GND -- 传感器 GND(黑)

  5V ---[2.2k]---+--- 传感器 OUT(黄)
                 |
               [10k] R1
                 |
                 +-------- GPIO10
                 |
               [20k] R2
                 |
                GND

  GPIO 高电平 = 5 * R2 / (Rpu + R1 + R2) = 5 * 20 / (2.2 + 10 + 20) = 3.11V
```

> **这一步不能省。** YF 系列水流传感器是 5V 供电、输出 5V 方波，
> ESP32-S3 的 IO **不是 5V 耐受**的（绝对最大 VDD + 0.3 = 3.6V）。
> 直连轻则引脚读数异常，重则烧脚。
>
> **那只 2.2k 也不能省。** 分压电阻本身就是个负载，会把高电平往下拽：
>
> | 上拉情况 | 送到 GPIO 的高电平 | 结果 |
> |---|---|---|
> | 自加 2.2k + 10k/20k | 3.11 V | 稳 |
> | 自加 4.7k + 10k/20k | 2.88 V | 可用 |
> | 只有传感器内部 10k + 10k/20k | 2.50 V | 贴着门限，危险 |
> | 只有传感器内部 10k + 10k/15k | 2.14 V | **低于门限，完全认不出高电平** |
>
> ESP32-S3 的输入高电平门限是 V_IH = 0.75 x 3.3 = **2.475V**。
> 接好后用万用表实测 GPIO10 对 GND 的高电平，**要在 2.8V 以上**。

### 液位开关（GPIO11）

```
  GPIO11 (内部上拉) --- 浮子开关 --- GND

  浮子抬起（有水）-> 闭合 -> 读低 -> levelOk = true
```

装在罐底上方约 10mm。注意选**常开（NO）**型，且用耐水的两芯线。

### 急停按钮（GPIO21）

```
  GPIO21 (内部上拉) --- 常闭按钮 --- GND

  不按  -> 闭合 -> 读低 -> 正常
  按下或线断 -> 断开 -> 读高 -> 急停（锁存，需 clear 复位）

  强烈建议同时把按钮的另一组触点串在泵的 12V 回路里：
    电池+ --- 保险丝 --- [急停常闭触点] --- 继电器 COM
  这样即使单片机死机，按下去也能硬切断。
```

### 漏水检测（GPIO18）

```
  GPIO18 (内部上拉) --- 裸铜线 A --- (2~3mm 间隙) --- 裸铜线 B --- GND

  两根线铺在背包底部（电池盒外围一圈）。遇水导通 -> 读低 -> 立即停泵 + 报警。
  不要镀锡：锡会钝化，久了就不导电了。用裸铜或镀金排针。
```

### I2C 总线（GPIO8 / GPIO9）

```
  3V3 ---[4.7k]---+---[4.7k]--- 3V3
                  |
  GPIO8 (SDA) ----+---- SDA(OLED / INA219)
  GPIO9 (SCL) ---------- SCL

  一条总线最多挂 8 个设备，OLED 和 INA219 地址不冲突，可以并联。
```

## 六、三块 ESP32-S3 怎么分工

| 板子 | 角色 | 说明 |
|---|---|---|
| A | **主控** | 跑本工程，负责控温、安全联锁 |
| B | **显示 / 网关**（可选） | 通过 UART 或 ESP-NOW 收 A 的数据，驱动 OLED、跑 BLE 手机端 |
| C | 备件 / 开发 | 烧坏了有得换 |

把无线功能放到 B 板是有原因的：WiFi 工作时约 100mA 且射频部分会发热，
挂在一个本身就要散热的装备上属于负收益。主控保持纯净，B 板可以塞在包里或者外接充电宝。
