# 接线总表 —— 逐触点（照这份文档就能把整机接起来）

> 用途：**事后复原**。每一行 = 一根线，全表一共 **85 根**。接完一行打一个勾。
> 编号规则：`A` 电源 / `B` 泵主回路 / `C` 控制端 / `D` 输入端 / `E` 调试。
> 全部以**元件上印的丝印**为准，不用记 GPIO 编号。

---

## 0. 先建 5 个汇流点（母线）

后面所有线都是往这 5 个点接。找个端子排或者直接拧成一坨都行，**每个点单独标个标签**：

| 汇流点 | 从哪来 | 供给谁 |
|---|---|---|
| **GND** | 电池负极 | 所有器件的 GND（公共地，必须全部接过来） |
| **+12V_F** | 保险丝的**出线端** | 两个降压板的 IN+、5 个继电器的 COM、电池分压 100k |
| **5V_A** | 降压板1 的 5V 输出 | 5 个继电器的 VCC、5 只 10k 上拉、水流传感器 VCC、水流 2.2k |
| **5V_B** | 降压板2 的 5V 输出 | **只给 ESP32 的 5V 脚** |
| **3V3** | 降压板2 的 3.3V 输出 | DS18B20 的 VDD、4.7k 上拉、ESP32 的 3V3 脚 |

> **为什么 5V 要分两条**：继电器线圈吸合瞬间会把 5V 拉出一个坑。
> 如果 ESP32 和继电器共用一条 5V，这个坑会把 MCU 打复位。分成两条最省心。

## A 组：电源（**先接这组，接完先量电压再往下**）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **A01** | BT1 `+` | F1 一端 | 电池正极先进保险丝 | ☐ |
| **A02** | F1 另一端 | **+12V_F** 汇流点 | 保险丝之后才叫 +12V_F | ☐ |
| **A03** | BT1 `−` | **GND** 汇流点 | 电池负极 = 系统公共地 | ☐ |
| **A04** | +12V_F | PS1 `IN+` | 降压板1 输入 | ☐ |
| **A05** | GND | PS1 `IN−` | | ☐ |
| **A06** | +12V_F | PS2 `IN+` | 降压板2 输入 | ☐ |
| **A07** | GND | PS2 `IN−` | | ☐ |
| **A08** | PS1 `OUT+` (5V) | **5V_A** 汇流点 | 只喂继电器线圈 | ☐ |
| **A09** | PS2 `OUT+` (5V) | **5V_B** 汇流点 | 只喂 ESP32 | ☐ |
| **A10** | PS2 `OUT` (3.3V) | **3V3** 汇流点 | 喂探头和 ESP32 的 3V3 | ☐ |

**停下来量一下**（用万用表直流档，黑表笔接 GND）：

```
□ 5V_A 对 GND    应该 4.9 ~ 5.1 V
□ 5V_B 对 GND    应该 4.9 ~ 5.1 V
□ 3V3  对 GND    应该 3.25 ~ 3.35 V
□ 12V_F 对 GND   应该 = 电池电压（11 ~ 12.6 V）
□ GND 对 GND     0 V
□ 量 F1 之后对 GND 的电阻（断电状态）—— 不能是 0 欧，否则是短路，别上电
```

> ⚠ **泵绝对不能从降压板取电。** 泵的 12V 必须直接来自电池（经保险丝和继电器触点）。
> 上一台泵和一块降压板就是这么烧的。

## B 组：泵主回路（**电流路径上只有保险丝和继电器触点**）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **B01** | +12V_F | K1 `COM` | 继电器1 的公共端 | ☐ |
| **B02** | K1 `NO` | M1 `+` | **必须用 NO，不能用 NC** | ☐ |
| **B03** | M1 `−` | **GND** 汇流点 | 泵的负极直接回电池负极 | ☐ |
| **B04** | D1 **阴极（有银环端）** | M1 `+` | 与 B02 同一个节点 | ☐ |
| **B05** | D1 阳极 | M1 `−` | 与 B03 同一个节点 | ☐ |

> **D1 接反 = 直接把 12V 短路**，会瞬间烧保险丝。装之前用万用表二极管档确认方向。
>
> **为什么用 NO 不用 NC**：NO 是"线圈不通电时断开"。这样断电、死机、线掉了，**泵自动停**。
> 用 NC 的话断电时泵反而在转，背在身上就是事故。

## C 组：控制端（ESP32 往外发指令）

### C-1 五路继电器线圈（**这一组是核心**）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **C01** | U1 `GPIO5` | K1 `IN` | 水泵 | ☐ |
| **C02** | U1 `GPIO6` | K2 `IN` | 备用 | ☐ |
| **C03** | U1 `GPIO7` | K3 `IN` | 备用 | ☐ |
| **C04** | U1 `GPIO15` | K4 `IN` | 备用 | ☐ |
| **C05** | U1 `GPIO16` | K5 `IN` | 备用 | ☐ |
| **C06** | 5V_A | K1 `VCC` | | ☐ |
| **C07** | GND | K1 `GND` | | ☐ |
| **C08** | 5V_A | K2 `VCC` | | ☐ |
| **C09** | GND | K2 `GND` | | ☐ |
| **C10** | 5V_A | K3 `VCC` | | ☐ |
| **C11** | GND | K3 `GND` | | ☐ |
| **C12** | 5V_A | K4 `VCC` | | ☐ |
| **C13** | GND | K4 `GND` | | ☐ |
| **C14** | 5V_A | K5 `VCC` | | ☐ |
| **C15** | GND | K5 `GND` | | ☐ |

> **K1~K5 的 `NC` 全部不接**（用不到常闭触点，接了反而危险）。
> **K2~K5 的 `NO` 留空**（备用继电器，以后接风扇/二号泵）。

### C-2 五只 10k 上拉（**最容易漏，漏了会「关不掉泵」**）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **C16** | R1 一端 | **5V_A** | | ☐ |
| **C17** | R1 另一端 | K1 `IN` | 与 C01 同一点 | ☐ |
| **C18** | R2 一端 | **5V_A** | | ☐ |
| **C19** | R2 另一端 | K2 `IN` | 与 C02 同一点 | ☐ |
| **C20** | R3 一端 | **5V_A** | | ☐ |
| **C21** | R3 另一端 | K3 `IN` | 与 C03 同一点 | ☐ |
| **C22** | R4 一端 | **5V_A** | | ☐ |
| **C23** | R4 另一端 | K4 `IN` | 与 C04 同一点 | ☐ |
| **C24** | R5 一端 | **5V_A** | | ☐ |
| **C25** | R5 另一端 | K5 `IN` | 与 C05 同一点 | ☐ |

> **为什么必须加**：ESP32 复位的那几百毫秒里，GPIO 是高阻（悬空）。悬空的 `IN` 会被水泵电刷的
> 干扰带偏，继电器乱吸合。有了这只 10k，悬空时 `IN` 被明确拉到 5V，继电器彻底截止。
>
> **这个模块是低电平触发**：`IN` 接 GND 就吸合。所以 10k **必须上拉到 5V**，不是下拉到 GND。

### C-3 蜂鸣器与 ESP32 自身供电

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **C26** | U1 `GPIO17` | LS1 `+` | 可选，不接也行 | ☐ |
| **C27** | LS1 `−` | **GND** | | ☐ |
| **C28** | U1 `5V` | **5V_B** | ★ 是 `5V` 脚，**不是 3V3 脚** | ☐ |
| **C29** | U1 `3V3` | **3V3** | | ☐ |
| **C30** | U1 `GND` | **GND** | ★ 少这一根，改什么极性都没用 | ☐ |

> **C30 是整份文档里最关键的一根。** ESP32 的 GND 必须和继电器模块的 GND 是同一个节点。
> 少了它，GPIO 推什么电平对继电器模块都没有意义，症状是「说 pump=ON 却不吸合、说 pump=OFF 反而一直转」。

### D-2 电池电压采样（可选）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **D18** | **+12V_F** | R6（100k）一端 | | ☐ |
| **D19** | R6 另一端 | R7（18k）一端 | ★ 这个中点接 GPIO1 | ☐ |

### D-3 水流传感器（★ 防烧泵，建议装）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **D22** | **5V_A** | FS1 `VCC`（红） | | ☐ |
| **D23** | **GND** | FS1 `GND`（黑） | | ☐ |
| **D24** | **5V_A** | R8（2.2k）一端 | | ☐ |
| **D25** | R8 另一端 | FS1 `OUT`（黄） | ★ 这个节点叫 FLOW_PU | ☐ |
| **D26** | FS1 `OUT` | R9（10k）一端 | 与 D25 同一点 | ☐ |
| **D27** | R9 另一端 | U1 `GPIO10` | ★ 中点进 ADC | ☐ |
| **D28** | R9 另一端 | R10（20k）一端 | 与 D27 同一点 | ☐ |
| **D29** | R10 另一端 | **GND** | | ☐ |

> 送到 GPIO10 的高电平 = 5 × 20 / (2.2+10+20) = **3.11 V**，门限 2.475V，有余量。
> **那只 2.2k 不能省** —— 只靠传感器内部上拉只有 2.50V，贴着门限会误读。

### D-4 开关量（全部是「引脚 — 开关 — GND」）

| # | 从（丝印） | 到（丝印） | 说明 | ☐ |
|---|---|---|---|---|
| **D30** | U1 `GPIO11` | SW1 一端 | 浮子液位开关（常开） | ☐ |
| **D31** | SW1 另一端 | **GND** | | ☐ |
| **D32** | U1 `GPIO18` | J1 裸铜线 A | 漏水探针 | ☐ |
| **D33** | J1 裸铜线 B | **GND** | A/B 相距 2~3mm | ☐ |
| **D34** | U1 `GPIO21` | SW2 `COM` | 急停/总电源（**常闭**） | ☐ |
| **D35** | SW2 `NC` | **GND** | | ☐ |
| **D36** | U1 `GPIO38` | SW3 一端 | 按键 A（固件暂未使用） | ☐ |
| **D37** | SW3 另一端 | **GND** | | ☐ |
| **D38** | U1 `GPIO39` | SW4 一端 | 按键 B（固件暂未使用） | ☐ |
| **D39** | SW4 另一端 | **GND** | | ☐ |

> **SW2 为什么用常闭**：不按时触点到 GND，引脚读低；按下时断开、被内部上拉拉高。
> 这样「**按下**」和「**线断了**」是同一种结果 —— 失效安全。用常开的话线断了没人知道。
>
> **强烈建议**：把 SW2 的**另一组触点串进泵的 12V 硬回路**（就在 B01 那条线上），
> 这样即使 MCU 死机，按下去也能物理切泵。

## 上电前 10 条检查

```
□  1. 泵的 12V 是从电池来的吗？中间只有保险丝和继电器 COM/NO，没有降压板？
□  2. 保险丝装了吗？在电池正极分流之前。
□  3. D1 阴极（有银环端）朝泵 + 吗？
□  4. 继电器用的是 COM + NO，不是 NC 吗？
□  5. K1~K5 的 IN 都各有一只 10k 上拉到 5V_A 吗？（5 只）
□  6. ESP32 的 GND（C30）和继电器模块的 GND 是同一个节点吗？
□  7. ESP32 的 5V 脚接的是 5V_B，不是 3V3 脚吗？
□  8. 断电状态下，量 +12V_F 对 GND 的电阻 —— 不能是 0 欧。
□  9. 泵放水里了吗？（干转几分钟阀片就废）
□ 10. 手放在电池接头上，闻到糊味立刻断。
```

## 最容易接错的 8 处（按踩坑频率排）

| # | 错在哪 | 症状 | 怎么查 |
|---|---|---|---|
| 1 | **ESP32 和继电器没共地**（漏 C30） | 说 `pump=ON` 不吸合；说 `pump=OFF` 反而一直转 | 通断档量 ESP32 的 GND 脚和模块 GND，必须 0Ω |
| 2 | **10k 漏了或接反方向** | 复位/烧录时泵自己抽一下 | `IN` 到 5V_A 之间必须有一只 10k |
| 3 | **D1 装反** | 一上电就烧保险丝 | 有银环那端朝泵 + |
| 4 | **继电器用了 NC 触点** | 断电时泵反而在转 | 换到 COM + NO |
| 5 | **泵从降压板取电** | 降压板冒烟、泵欠压堵转 | 泵的 12V 必须直连电池 |
| 6 | **4.7k 上拉到 5V** | GPIO4 被打坏 | 必须拉到 3V3 |
| 7 | **排针插错一格** | 全乱 | 照第 1 节的 J1/J3 顺序数 |
| 8 | **5V_A 和 5V_B 并成一条** | 继电器一吸合 ESP32 就复位 | 两条独立的 5V |

## 接完之后的验证步骤

```
# 1. 只接电池 + 降压板，不接 ESP32：量 5V_A / 5V_B / 3V3 都对
# 2. 接 ESP32（USB 线先别插），上电，看灯
# 3. 插 USB 线，开串口 115200：

scan                       # 应该列出 5 个探头 ROM
map skin_chest 0           # 把 1 号探头绑成"胸前体表"（会自动存 NVS）
relay test                 # 每 5 秒翻一次 IN，用耳朵确认哪次咔哒 -> 确认模块是低电平触发
pump on                    # 强制开泵
pump off                   # 应该真的停（停了才说明开漏驱动生效）
enable on                  # 打开自动控温
status                     # reason 行会直接告诉你为什么开/为什么不开
```
