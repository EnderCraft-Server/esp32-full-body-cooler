# 接线与电源审查

> 结论先说：**大方向全对**（高边开关、NO 触点、5V 供电的继电器、4.7k 上拉、12V 降压给 ESP32）。
> 但有 **6 处必须改**，否则轻则继电器触点几个月就烧黑、重则 ESP32 被电机尖峰打复位。

---

## 一、你给的原方案，逐条核对

| 你的接法 | 判定 | 说明 |
|---|---|---|
| 12V 电池正极 → 继电器 COM | 正确 | 高边开关，正确 |
| 继电器 NO → 泵正极 | 正确 | 用 **NO**（常开）而不是 NC，断电时泵不转，正确 |
| 泵负极 → 12V 负极 | 正确 | 正确 |
| 12V → DC-DC 降压 → 5V → ESP32 + 继电器 VCC | 需改 | 方向对，但**不能让 ESP32 和 5 个继电器共用同一条细线**，见问题 4 |
| ESP32 GPIO → 继电器 IN | 需改 | 电平兼容没问题，但**上电瞬间必须有外部电阻兜底**，见问题 2 |
| DS18B20 数据线加 4.7kΩ 上拉 | 正确 | 5 个探头并联一条总线没问题 |

## 二、必须改的 6 处

### 1. 【最要紧】泵两端加续流二极管

365 泵是**有刷直流电机**，本质是一个大电感。继电器断开瞬间，线圈里的电流被硬切断，
会产生几百伏的反向尖峰：

* 继电器触点之间**拉弧** —— 标称 10A 是**阻性负载**额定值，感性负载通常要打到 5 折甚至更低。
  你这个 0.45A 的泵电流不大，但 12V 感性负载拉弧会慢慢把触点烧出麻点和凹坑，
  典型表现是用了几个月之后继电器咔哒响但泵不转（触点接触电阻变大）。
* 尖峰顺着 12V 母线往回流，通过 DC-DC 耦合到 3.3V，**让 ESP32 复位或 1-Wire 时序错乱**。

**做法**：一只二极管**反向并联在泵的两个接线端子上**（阴极 = 有环的那一端，接 +12V 侧）。

* 型号：**1N5408**（3A / 1000V，便宜大碗）或 **SS34 / 1N5822**（肖特基，压降更低）。
* 方向千万别装反 —— 反了就是**直接把 12V 电源短路**，会立刻烧保险丝。
* 二极管**尽量靠近泵**，引线越短越好（引线本身也是天线）。

这一块钱的东西解决 90% 的「电机一启动单片机就死机」问题。

### 2. 【最要紧】确保上电瞬间泵不会自己抽一下

ESP32 复位的那几百毫秒里，GPIO 处于**高阻输入**状态，继电器模块的 IN 引脚等于**悬空**。

* 如果模块是高电平触发：IN 悬空有可能被内部电路拉高 → **上电泵就转**。
* 如果是低电平触发：IN 悬空一般被拉高 → 不转，相对安全。

固件里已经做了防护（`PumpController::begin()` 里**先写输出电平、再切成 OUTPUT**），
但那只覆盖 `begin()` 之后的时刻，**从复位到 `begin()` 之间还有几百毫秒是固件管不到的**。

**做法**：在继电器模块的 IN 引脚和 GND 之间焊一只 **10kΩ 下拉电阻**
（低电平触发的模块则改成 IN 到 5V 的 10kΩ 上拉）。

**验收方法**：把泵接上但**不给水**，反复按 ESP32 的 RST 键 20 次，
每次只上电 2 秒就断电，看泵有没有啪的一下。有 → 电阻没接对。

### 3. 【最要紧】泵的干扰必须隔离，否则 ESP32 会随机复位

泵启停时 12V 母线会塌陷 + 叠加尖峰（电机启动电流是额定值的 3~5 倍，
0.45A × 4 ≈ **2A 的瞬间冲击**）。措施从便宜到彻底：

1. **泵的两根线拧成麻花**（双绞），并且**不要和信号线、传感器线捆在一起走**。
   传感器线（DS18B20 单总线对时序敏感）和泵电源线并行走线，是读数乱跳的头号元凶。
2. 泵接线端子处并 **100nF 陶瓷电容 + 100uF 电解电容**。
3. DC-DC 模块的 12V 输入处并 **470uF~1000uF 电解 + 100nF 陶瓷**。
4. **给 ESP32 单独用一路 DC-DC**（你有 3 个模块，别省）。
   泵和继电器模块走一路，ESP32 + 探头走另一路，只在电池负极处单点共地。

**验收方法**：固件里用 `mon 3` 和 `moff 3` 把最短启停改成 3 秒，
然后 `pump on` 让它自动跑 30 分钟（约 300 次启停）。
同时串口开 `log on` 抓日志，看有没有丢字符、时间戳跳变、或者板子重启（会重新打印启动横幅）。

### 4. 5 个继电器模块不要从 ESP32 板子取 5V

常见 5V 继电器模块每只吸合时约 **85mA**（线圈 70mA + 光耦 15mA）。
5 只同时吸合 ≈ **425mA**，已经接近很多 DC-DC 模块的实际余量和开发板 USB 口的能力。

* **直接从 DC-DC 的 5V 输出取电**，导线 >= 22AWG。
* 在继电器模块附近放一只 **100uF** 电解，吸收线圈吸合的瞬时电流。
* ESP32 开发板自己的 5V 脚（VIN）只供板子本身。

你的项目实际只用 1 个继电器，所以现在是 85mA，问题不大。
但既然固件里 `aux` 命令可以单独测剩下的 4 路，将来加 TEC / 风扇时就要按 425mA 规划。

### 5. 锂电池保护：欠压 + 保险丝，一个都不能少

* **保险丝**：电池正极出口串一只 **5A 快熔**，位置在**分流给继电器和 DC-DC 之前**。
  锂电短路电流能到几十安，不加保险丝就是点焊机。
* **欠压保护**：3S 锂电放到 9.0V 以下就永久损伤。绝大多数 DC-DC 降压模块**没有欠压关断**，
  会一直抽到 6V 以下。必须加 **3S BMS**，或者一只低压断电模块。
* **3 个电池组不要直接并联**。容量 / 内阻 / 老化程度不一致时会产生环流，
  轻则自放电，重则热失控。**一次用一个，用完换**。要并联就得加理想二极管均流板。

另外注意：12.6V 是 3S 的满电电压，放电到 9V 时泵的转速会明显下降
（有刷电机转速大致正比于电压），出水量大概掉到 75%。这对控温没影响（固件按温度闭环），
但要知道「电池快没电时降温会变慢」。

### 6. 湿区防护

12V 属于安全电压（< 36V），湿手碰到不会触电，但**水 + 锂电池在同一个背包里**是真风险。

* 电池放在**独立的防水盒**里，和水箱之间加一块**隔板**；
* 所有压接端子套热缩管，接头处打硅胶；
* ESP32 和 DC-DC 放进防水盒，盒底垫高 5mm，盒底打一个**朝下的**排水小孔；
* 充电时**绝对不要**背着或者靠近水路 —— 12.6V/2A 充电器进水是唯一可能真正出事的场景。

固件里留了一个**可选的漏水检测**（`include/config.h` 里 `ENABLE_LEAK_SENSOR`）：
在背包底部铺两根相距 2~3mm 的裸铜线接 GPIO18，遇水导通 → 立即停泵 + 蜂鸣器报警。
默认关闭（没接线时引脚悬空会误报），接好线再改成 `1`。

## 三、ESP32-S3 引脚分配（固件里已按这个写死）

| 功能 | GPIO | 备注 |
|---|---|---|
| DS18B20 单总线（5 探头并联） | **4** | 4.7kΩ 上拉到 **3V3**（不是 5V！） |
| 继电器 1 → 水泵 | **5** | 主输出 |
| 继电器 2 / 3 / 4 / 5 → 备用 | 6 / 7 / 15 / 16 | 用 `aux 1` ~ `aux 4` 单独开合 |
| 有源蜂鸣器（可选） | 17 | 没接也能跑 |
| 漏水检测（可选） | 18 | 默认关闭 |
| 板载状态灯 | 48 | DevKitC-1 v1.0 是 WS2812 彩灯 |

**这些脚绝对不要用**：

| GPIO | 原因 |
|---|---|
| 0 / 45 / 46 | strapping 脚，上电电平决定启动模式，接负载会导致烧录失败或启动异常 |
| 19 / 20 | ESP32-S3 原生 USB D- / D+ |
| 26 ~ 32 | 内部 SPI flash |
| 33 ~ 37 | **OPI PSRAM**（N16R8 模组，占用了就丢 8MB PSRAM） |
| 43 / 44 | UART0，接板载 CH343 串口桥（就是你电脑上的 COM 口） |

> 4.7kΩ 上拉一定要接 **3V3**。接到 5V 会经过上拉电阻倒灌进 GPIO，
> ESP32-S3 的 IO 不是 5V 耐受的，轻则读数乱跳重则烧脚。

## 四、继电器模块触发电平怎么测（10 分钟的事）

「丢石头」这类模块触发电平是可跳线的，**不同批次可能不一样**，别猜，实测：

1. 只给模块接 5V 和 GND，**不接泵**，用万用表蜂鸣档测 COM-NO 通断。
2. IN 引脚**悬空**：听有没有咔哒 → 记录（这就是上电瞬间的状态）。
3. IN 接 **5V**：听有没有咔哒。
4. IN 接 **GND**：听有没有咔哒。
5. 把 IN 接到 ESP32 的 GPIO，用 `aux 1 on` 和 `aux 1 off` 再各测一次 ——
   确认 **3.3V 的高电平也够驱动**。绝大多数模块可以，因为光耦 LED 串了 1k 电阻，
   3.3V 时电流约 (3.3 - 1.2) / 1000 ≈ 2.1mA，处在可用区间边缘，**一定要实测**。

据此设置 `include/config.h`：

```c
#define RELAY_ACTIVE_HIGH  1   // 高电平触发写 1，低电平触发写 0
```

**上电默认状态必须让泵停**，这是硬性安全要求。

## 六、上电量清单（跳过必炸，别跳）

- [ ] 电池正极出口有 5A 保险丝
- [ ] 泵两端有续流二极管，**方向没接反**
- [ ] 继电器 IN 有 10kΩ 上拉 / 下拉
- [ ] 继电器模块 VCC 来自 DC-DC，不是 ESP32 的 5V 脚
