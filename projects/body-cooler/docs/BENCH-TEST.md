# 台架测试（继电器 + 水泵 + 电池）

## 事故记录（2026-10，已烧毁 1 台泵 + 1 块电源板）

| 项 | 当时的状态 | 后果 |
|---|---|---|
| 泵供电 | **从降压板的 12V 输出取电**（应该直接从电池取） | 降压板烧毁 |
| 保险丝 | **没装**（还没到货） | 没有任何过流保护 |
| 续流二极管 | **没装** | 电机反峰倒灌回降压板 |
| 结果 | 降压板先崩 → 泵欠压堵转 → 电流暴涨 | **泵 + 板子一起烧，冒烟** |

**结论：泵的电流路径上只能有「保险丝 + 继电器触点」两样东西。**

## 故障记录：接触器不吸合 / 探头扔进 50°C 热水也不开泵（2026-10-06，固件已修复）

**现象**

```
scan     -> idx 0  28CB4CAF11250680  UNASSIGNED  34.6     <- 角色丢了
状态灯    -> 红色快闪（FAULT）
水泵      -> 从不启动，继电器永不吸合
```

**根因：NVS 键名超过 15 字符，角色映射静默写入失败**

原代码把角色存成 `role_<16位ROM>` 的键名 = 3 + 16 = **21 字符**，
而 ESP-IDF 的 NVS 键名上限是 **15 字符**。`putUChar()` 直接返回失败，
但代码没检查返回值 → 每次断电/重启后角色都是空的。

于是启动时：

```
探头没有角色 -> skinAvg() 返回 NaN, water_out 也是 NaN
             -> updateSafetyLatch(): !haveSkin && !haveWOut -> enter = true
             -> m_safetyLatched = true -> 状态机进入 ST_FAULT
             -> 继电器被强制断开，无论水温多高都不吸合
```

所以「探头放 50°C 水里也不开泵」不是因为温度不够，是**联锁把泵锁死了**——
固件根本不知道哪个探头是体表探头。

**修复（3 处）**

| 文件 | 改动 |
|---|---|
| `src/tempsensor.cpp` | 短键名：`r<i>` 存「序号→ROM」，`m<i>` 存「序号→角色」，都 ≤ 3 字符 |
| `src/tempsensor.cpp` | `scan()` 重扫时按 ROM 把角色贴回去，重排序号不会串角色 |
| `src/console.cpp` | `scan` 不再调用 `loadRoles()`（原来它先清空内存角色，会抹掉刚 map 好的）；`map` 立即落盘 |

**另外新增：`status` 会直接告诉你为什么泵不开**

```
state   : REST      pump=OFF  force=auto enabled=yes mode=HYSTERESIS
reason  : 等最短停机结束：还差 23 秒        <- 新增行，一句话解释
```

常见 reason：

| reason | 含义 | 怎么解决 |
|---|---|---|
| `控温总开关关闭（enable on 打开）` | `enable off` 了 | 发 `enable on` |
| `等最短停机结束：还差 N 秒` | 上电后 30 秒内的正常等待 | 等，或 `pump on` 强制 |
| `体表 xxC < 开泵阈值 yyC` | 温度不够，本来就不该开 | 正常 |
| `安全联锁已锁：没有绑角色：体表/水温探头都没 map` | 角色丢了 | `scan` → `map skin_chest 0`（会自动存） |
| `安全联锁已锁：体表温度低于下限（过冷保护）` | 低于 30°C | 检查设定或 `clear` |

**实测验证（UART/USB 串口日志）**

```
map skin_chest 0   ->  OK: 28CB4CAF11250680 -> SKIN_CHEST    (已写入 NVS)
reboot             ->  scan 仍然显示 SKIN_CHEST      <- 角色这次活过了重启
enable on          ->  reason: 等最短停机结束：还差 23 秒
等待 30 秒          ->  state: PUMPING  pump=ON      <- 继电器自动吸合
```

**踩坑提醒：上电后 30 秒内泵不会启动**

`minOff = 30s` 是保护继电器触点和泵阀片的物理下限，上电时也照样生效。
所以「刚插上电，探头是热的，泵却不动」是**正常现象**，看 `reason` 行确认。
台架想立刻动泵就发 `pump on`（手动强制，绕过所有判断）。

# 一点五、触发电平接反了会怎样（★ 现场最容易踩的坑）

5V 光耦继电器模块有 **高电平触发(H)** 和 **低电平触发(L)** 两种，外形几乎一样，
有些板上还有跳线帽能切换。选错了**症状是「反着来」**：

| 固件里看到的 | 实际继电器 | 你观察到什么 |
|---|---|---|
| `state: PUMPING pump=ON` | **不吸合** | 该转的时候不转，怎么加热水都不开泵 |
| `state: FAULT pump=OFF` | **吸合** | 「泵没有关停，一直在转」，`enable off` 都停不下来 |
| `state: STANDBY pump=OFF` | 吸合 | 一上电泵就一直转，只有拔电池才停 |

**出现「反着来」先怀疑两件事**：

1. **触发电平选错**（下面这套流程按这个查）；
2. **ESP32 和继电器模块没有共地** —— 这种情况下 GPIO 的高/低对模块来说毫无意义，
   IN 相对模块 GND 的电平是漂的，表现会和「极性反了」一模一样。
   ★ 实测：`pump on` 时用万用表量 **IN 对模块自己的 GND**，不是对 ESP32 的 GND。

> 本项目实测：**IN 短接 GND 就吸合 -> 低电平触发(L)**，固件用 `RELAY_ACTIVE_HIGH 0`。

### ★ 第三种情况：极性对、线也对，但继电器就是放不掉

**实测记录（本项目真实踩到）**

```
把 GPIO5 直接短接到 GND        -> 泵转          (接线/极性/模块 全部正常)
固件输出 LOW  (0V)             -> 泵转          ✓
固件输出 HIGH (3.3V)           -> 泵【仍然】转   ← 问题在这
ESP32 复位(引脚高阻)            -> 泵停          ← 关键线索！
```

**原因：3.3V 不是这个模块的"高"。**

5V 光耦继电器模块的输入是：

```
模块 VCC(5V) ──[限流电阻]── 光耦 LED ──► IN 引脚
```

LED 的阴极接在 IN 上。IN 停在 **3.3V** 时，LED 上还剩 `5 - 3.3 - Vf(约1.2V) ≈ 0.5V` 的压差，
仍有微弱电流流过 —— 对灵敏的光耦来说**足够把继电器维持住**。
只有把 IN 真正拉到 **5V**（或让它悬空到没有电流回路），LED 才彻底截止。

* ESP32 推不出 5V -> 推挽输出解决不了。
* **引脚变高阻时 LED 没有回路 -> 彻底截止** -> 这就是「ESP32 一复位泵就停」的原因。

**解决：开漏驱动（固件已支持，不用改硬件电路）**

```
relay od      # 切到开漏：吸合 = 引脚推低 0V；释放 = 引脚变高阻
relay pp      # 切回推挽（默认）
```

配一只 **10k 电阻：模块 IN ──[10k]── 模块 VCC(5V)**（推荐但不是必须，
作用是让高阻状态被明确拉到 5V，抗电机干扰）。

切到 `relay od` 后 `status` 会这样显示：

```
relay   : IN实测=HIGH  指令=高阻(靠10k上拉)  驱动=开漏  极性=低电平触发  线圈=释放(泵停)
```

### 还有一个要查的：模块 VCC 到底几伏

万用表量 **模块 VCC 对 模块 GND**：

| 读数 | 说明 |
|---|---|
| 5.0V 左右 | 正常，用 `relay od` 即可 |
| 12V | **接错了** —— 模块是 5V 的，被接到 12V 上了，继电器会发热、寿命大减 |
| 3.3V | 接到 ESP32 的 3V3 上了，线圈可能吸不牢 |
| 0V | VCC 没接 |

## 怎么确认 / 怎么改（不用重新编译）

```
relay           # 看当前极性和 IN 引脚实测电平
relay test      # ★每 3 秒把 IN 翻一次，共 6 次 —— 用耳朵听
                 #  记下「哪一次咔哒」：
                 #    IN=HIGH 时咔哒  ->  relay high
                 #    IN=LOW  时咔哒  ->  relay low
relay high      # 改成高电平触发，立即保存到 NVS
relay low       # 改成低电平触发，立即保存到 NVS
```

改完极性后 `status` 会这样显示，可以直接对着看：

```
relay   : IN=LOW(实测)  极性=高电平触发  线圈=释放(泵停)
```

## 如果反了但一时不想改固件

低电平触发模块的输入通常是 `VCC ──[限流电阻]── 光耦LED ── IN`，
所以 **IN 悬空 = 没电流 = 释放**；高电平触发正好相反。
10k 电阻的方向必须跟着极性走，接反等于给模块加了反向偏置。

## 缺电阻会怎样

低电平触发模块的输入通常是：

```
模块 VCC(5V) ──[内部限流电阻]── 光耦 LED ── IN 引脚
```

所以 **IN 悬空 = 没有电流 = 继电器释放** —— 浮空本身是安全的（这点和高电平触发**相反**）。
缺上拉电阻的风险不在启动瞬间，而在于：

| 风险 | 表现 |
|---|---|
| 跳线当天线接收电机干扰 | 泵启停时继电器偶尔**无规律地啪一下** |
| ESP32 输出高只有 3.3V（模块 VCC 是 5V） | 压差只有 1.7V，光耦 LED 电流偏小，**极端情况下继电器释放不干脆** |

代码里已经做了能做的：`begin()` **先打开内部上拉（约 45k）再切输出**，
让 IN 在没人管时尽量保持高。但内部上拉太弱，挡不住强干扰。

## 没有电阻时怎么办

1. **先直接试**，但一定要用万用表确认：
   - 串口发 `pump off`（或等它进入停泵阶段）
   - 万用表**通断档**量继电器 **COM 和 NO** —— 应该是**断开（不通）**
   - 再发 `pump on`，应该变**导通**
   - 若 off 状态量出来是通的、或几百欧阻值 -> **继电器没完全释放** -> 必须加电阻
2. **把 IN 的跳线尽量剪短**，并**远离水泵电源线**（别平行捆一起）
3. **电阻到了立刻补上**：一端插 IN，另一端插模块 VCC(5V)
4. 上电时**盯着继电器听**：若上电瞬间啪一下再释放，说明浮空窗口有误动作

# 二、上电前必查（3 分钟，能省一次烧板子）

1. **万用表通断档**量「汇流点 A」和「汇流点 B」之间 —— **不能导通**。导通就是短路，立刻查线。
2. 确认继电器 **COM 和 NO** 用对了（**不是 NC**）。用 NC 的话逻辑反过来，泵会一直转。
3. 确认 **续流二极管方向**：有银环的一端接**水泵正极**。接反 = 直接把 12V 短路，会烧保险丝。
4. 确认 **ESP32 的 5V 脚**接的是 DC-DC 输出，**不是 3V3 脚**。
5. 确认**水泵正极接的是继电器 NO**，不是直接接电池正极（否则泵会一直转，不受控）。

# 四、固件现在是什么行为

烧进去的固件**默认就是台架测试模式**，上电后：

```
每 30 秒开泵 ── 每 30 秒停泵 ── 循环
```

**它完全绕过安全联锁** —— 不管有没有温度探头、水温多少、有没有缺水，都按固定节拍开关。

## 串口命令

| 命令 | 作用 |
|---|---|

# 五、这次测试要验证什么

| 项 | 通过标准 |
|---|---|
| 继电器能吸合/释放 | 每 30 秒听到一声清脆的咔哒，不是拖泥带水的嗡嗡声 |
| 时序正确 | 用秒表掐：开 30 秒 ±1 秒，停 30 秒 ±1 秒 |
| 泵确实转 | 接水后能听到水流声 / 看到水在管里动 |
| **ESP32 不重启** | 连续跑 20 分钟，串口不出现新的启动横幅 |
| 串口不丢字符 | `log on` 期间输出连续，没有乱码 |
| 电池电压不塌 | 泵启动瞬间 DC-DC 输出 5V 不抖到 4.5V 以下 |

## 重点看第 4 项

泵启动瞬间电流是额定的 3~5 倍（0.45A × 4 ≈ **2A**），会在 12V 母线上砸出一个坑，
同时电刷打火产生高频尖峰。**如果 ESP32 会因此复位，说明续流二极管和滤波电容没做到位。**

测试方法：`log on`，让它跑 20 分钟（约 20 个循环），盯着串口。
如果出现新的 `===== body-cooler =====` 启动横幅 → **ESP32 复位了** → 回去查 P0-1（续流二极管）和 P0-3（滤波电容）。

# 六、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| **反着来**：固件说 ON 却不吸合 / 说 OFF 反而一直转 | ① 触发电平选反 ② ESP32 与模块**没共地** | 先量 IN 对**模块 GND**；再 `relay test` 听咔哒声定位；极性用 `relay high`/`relay low` 现场切 |
| 继电器一直吸合不释放 | 用了 NC 触点 | 改接 COM + NO |
| 继电器一直不动作（极性已确认正确） | IN 没接对 / 模块 VCC 没 5V | 万用表量 IN 对 GND：`pump on` 时应该等于吸合电平 |
| 上电瞬间泵抽一下 | IN 悬空被拉高 | 加 10k 下拉（接线表第 15/16 根） |
| 泵转了但没水 | 没灌引水 / 进水管漏气 | 从回水管倒水进罐，把泵泡一下 |
| ESP32 反复重启 | 电机干扰 | 查续流二极管方向、加分路 DC-DC、加滤波电容 |
| 串口乱码 | 波特率不对 | 必须是 115200 |
| 泵转速明显变慢 | 电池电压低了 | 量电池，低于 10.5V 该充电了 |
