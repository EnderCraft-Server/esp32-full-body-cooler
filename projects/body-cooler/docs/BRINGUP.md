# 桌面测试流程（分 7 步，别跳步）

原则：**从最便宜、最不容易炸的东西开始。** 每一步都确认通过了再进下一步。
每一步只引入一个新变量，出问题时才能定位。

---

## 第 0 步：不接任何外设，只上 ESP32

```powershell
# 在工作区根目录执行
.\scripts\pio.ps1 run -d .\projects\body-cooler -t upload --upload-port COM5
.\.venv\Scripts\python.exe .\scripts\serial_capture.py --port COM5 --seconds 8 --reset
```

**期望看到**：

```
=============================================================
  body-cooler  --  ESP32-S3 全身降温器固件
  build ...
=============================================================
chip       : ESP32-S3 ...
flash      : 16 MB    psram: 8386279 bytes
--- pin map ---
  DS18B20 bus : GPIO4  (4.7k 上拉到 3V3)
  relay pump  : GPIO5 (高电平 触发)
...
DS18B20     : 总线发现 0 个探头
  !! 没找到温度探头 —— 自动控温会被安全联锁锁住（state=FAULT）。
  !! 台架测试可用: pump on / pump auto 手动驱动继电器。
```

**通过标准**：`flash` 是 16 MB，`psram` 是约 8 MB，没有重启循环。

> PSRAM 显示 0 → `platformio.ini` 里的 `-DBOARD_HAS_PSRAM` 丢了，见技能文档坑 4。

输入 `help` 和 `status` 确认串口命令行有响应。

---

## 第 1 步：接 1 个 DS18B20（带 4.7k 上拉）

接线：`VDD -> 3V3`、`GND -> GND`、`DQ -> GPIO4`，`4.7k` 电阻跨接在 **DQ 和 3V3** 之间。

```
scan
```

**期望**：列出 1 行 `28FF........` 的 ROM。

**温度校准**：把探头丢进**冰水混合物**（冰 + 少量水，搅匀），等 2 分钟，读数应该是 **0.0 正负 0.5 度**。
常温下应该接近室温。偏差超过 1 度 → 探头有问题，或者线太长 / 上拉电阻太大。

总线上一个探头都没有时的排查顺序：

1. 4.7k 上拉是不是接的 **3V3**（接 5V 会烧 GPIO）；
2. DQ 是不是真的接到了 GPIO4；
3. 探头三根线的颜色定义 —— **不同厂家不一样**！红的可能是 VDD 也可能是 DQ，
   用万用表量一下二极管压降确认；
4. 线太长（超过 5 米）→ 把上拉换成 2.2k。

---

## 第 2 步：接齐 5 个探头并分配角色

```
scan                          # 确认 5 个都在
map water_out   0             # 罐出水口（最冷点）
map water_ret   1             # 回水口（最热点）
map skin_chest  2             # 胸前体表
map skin_back   3             # 后背体表
map ambient     4             # 背包内环境
roles                         # 复查
save                          # 写进 NVS，掉电不丢
```

**角色分工的理由**：

| 角色 | 位置 | 作用 |
|---|---|---|
| `water_out` | 罐出水口 / 泵入口 | 系统最冷点，用于过冷保护（`wmin`） |
| `water_ret` | 回水进罐处 | 与出水口的温差 = 从身上带走的热量，用于估算制冷功率和判断冰袋是否失效 |
| `skin_chest` / `skin_back` | 贴身速干衣内侧 | 控温主反馈量（两个取平均） |
| `ambient` | 背包内 | 监控罐外壁结露风险 |

> 探头用**医用胶布 / 薄敷贴**固定在速干衣内侧，金属探头不要直接压在皮肤上，
> 长时间会形成压痕和局部冷点 —— 中间垫一层薄棉布。

---

## 第 3 步：只测继电器模块（不接泵！）

这一步是为了确定**触发电平**和**上电行为**，见 `docs/WIRING-REVIEW.md` 第四节。

```
aux 1 on
aux 1 off
```

听继电器有没有咔哒声，用万用表蜂鸣档量 COM-NO 通断。

**关键测试**：按住 RST 键反复复位 20 次，听继电器有没有在上电瞬间乱响。
有 → 必须在 IN 引脚上加 10k 上拉 / 下拉，然后回到第 3 步重测。

确认后设置 `include/config.h` 里的 `RELAY_ACTIVE_HIGH`，重新编译烧录。

---

## 第 4 步：接泵（先不接水），测电磁干扰

**泵绝对不能长时间空转。** 每次开 **不超过 3 秒**，间隔 15 秒以上。

```
pump on
# 等 3 秒
pump off
```

重复 20 次左右，同时开着 `log on` 看串口。

**通过标准**：

* 泵每次都正常启动 / 停止；
* 串口**不丢字符**、时间戳不跳变；
* ESP32 **不重启**（没有重新打印启动横幅）；
* 继电器吸合的声音干脆（不是拖泥带水的嗡嗡声）。

失败 → 按 `docs/WIRING-REVIEW.md` 问题 1 和问题 3 加二极管和电容。

---

## 第 5 步：加水，测密封和循环

按 `docs/SEALING-REVIEW.md` 第五节做：

1. **静态保压**：堵住进出口，纸巾垫底，静置 30 分钟看渗漏；
2. **动态循环**：装满水，`pump on` 连续跑 30 分钟，观察所有接头；
3. **倒置测试**：罐子倒过来放 5 分钟，模拟背包晃动。

注意听泵的声音 —— **明显的咕噜咕噜气泡声 = 进水口漏气**，检查卡箍和宝塔头。

顺便记下**实际流量**：用一个量杯接住出水口，跑 60 秒，量出多少毫升。
然后用 `flow <L/min>` 把实测值填进去，`savecfg` 保存。
（`flow` 只影响串口打印的估算制冷功率，不影响控温逻辑，但填准了很有参考价值。）

---

## 第 6 步：控温回路测试（不穿上身）

这一步用温度计和水杯来骗固件。

1. 把 `skin_chest` 和 `skin_back` 两个探头一起丢进 **35 度的温水**里；
2. `water_out` 探头丢进 **冰水**里（模拟罐里出来的冷水）；
3. `enable on`，开 `log on`。

**期望行为**：

* 体表读数 35 度 > 目标 33 度 + 回差一半 → **泵启动**；
* 把体表探头换到 **32 度的水**里 → 泵仍然继续跑（因为还没到最短运行时间 20 秒，
  而且回差下限是 32.5 度）；
* 换到 **28 度的水**里 → 会触发 `WARN_SKIN_LOW`，**泵立即停**（安全联锁打断最短运行时间），
  LED 变红闪，`state=FAULT`；
* 把体表探头放回 35 度水 → `clear` 之后恢复正常；
* 把 `water_out` 探头从冰水里拿出来放室温 → 超过 32 度时触发 `WARN_WATER_HIGH`。

**再测占空比模式**：

```
mode 1        # 时间比例（慢 PWM）
log on
```

把体表探头放在 34 度温水里，观察泵是不是按 3 分钟一个周期间歇运行，
`duty10m` 应该在 30% ~ 70% 之间随温度变化。

**验证「不能 PWM」这条约束是否被遵守**：
整个测试过程中，继电器**只应该整段开、整段关**，
任何情况下都不应该听到高频哒哒哒的声音。最短运行 20 秒 / 最短停机 30 秒保证了这一点。

---

## 第 7 步：上身测试（最后一步）

**前置条件：第 0 ~ 6 步全部通过。**

1. 先穿**紧身速干衣**打底，软管走在速干衣外面、外套里面；
2. 第一次只跑 **10 分钟**，全程有人陪着，随时能拔掉电源；
3. 观察：体表温度有没有降下来、有没有局部过冷 / 发麻 / 起疹子、
   冷凝水有没有渗到衣服上；
4. 逐步加长到 30 分钟、60 分钟。**单次不要超过 60 分钟。**

**手感比温度数字重要**：如果觉得某一段特别冷或者刺痛，立刻停，
那段管子要么加一层布垫，要么换个走向。

## 附：常用串口命令速查

| 命令 | 作用 |
|---|---|
| `status` | 打印一次完整状态（温度 / 状态机 / 报警 / 统计） |
| `scan` | 重新扫描总线并列出 ROM / 角色 / 温度 |
| `log on` | 每 2 秒自动打印一次状态；`rate 5000` 改成 5 秒 |
| `pump on` / `pump off` / `pump auto` | 手动强制 / 交回自动 |
| `enable on` / `enable off` | 控温总开关 |
| `clear` | 清除安全联锁（过冷 / 漏水故障后手动复位） |
| `aux 1 on` | 手动开 1 号备用继电器（1 ~ 4） |
| `target 33.0` | 改体表目标温度 |
| `band 1.0` | 改回差 |
| `wmin 10` | 改水温下限（建议实测后调到 10 ~ 12） |
| `mode 1` | 切到时间比例（慢 PWM）模式 |
| `savecfg` | 保存设定到 NVS |
| `save` | 保存探头角色映射到 NVS |
