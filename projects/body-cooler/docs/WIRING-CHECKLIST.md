# 接线总表 —— 逐触点

> 每行一根线。**85 根。** 接完一行打个勾。
> 五列固定格式：`元件名称 · 触点 → 连接到元件 · 连接到触点`，最后一列说明。

## 0. 先建 5 条母线

后面所有线都往这 5 个点接。找个端子排、或者直接拧成一坨，**每个点单独贴标签**。

| 母线名 | 从哪来 | 供给谁 |
|---|---|---|
| **GND** | 电池负极柱 | 所有器件的 GND，一个都不能漏 |
| **+12V_F** | 保险丝出线端 | 两个降压板 IN+、5 个继电器 COM、电池分压 100k |
| **5V_A** | 降压板1 的 5V 输出 | 5 个继电器 VCC、5 只 10k、水流传感器 |
| **5V_B** | 降压板2 的 5V 输出 | **只给 ESP32 的 5V** |
| **3V3** | 降压板2 的 3.3V 输出 | DS18B20 VDD、4.7k 上拉、ESP32 的 3V3 |

## 上电前 10 条检查

```
□  1. 泵的 12V 是从电池来的吗？中间只有保险丝和 K1 的 COM/NO？
□  2. 保险丝装在电池正极分流之前了吗？
□  3. D1 阴极（有银环端）朝水泵的 + 柱吗？
□  4. K1 用的是 COM + NO，不是 NC 吗？
□  5. K1~K5 的 IN 都各有一只 10k 上拉到 5V_A 吗？（5 只）
□  6. ESP32 的 GND 和继电器模块的 GND 是同一个点吗？
□  7. ESP32 的 5V 接的是 5V_B，不是 3V3 吗？
□  8. 断电量 保险丝出线端 对 GND 的电阻 —— 不能是 0 欧。
□  9. 泵放水里了吗？
□ 10. 手放在电池接头上，闻到糊味立刻断。
```

## 最容易接错的 8 处

| # | 错在哪 | 症状 | 怎么查 |
|---|---|---|---|
| 1 | 漏了 `ESP32·GND → GND` | 说 `pump=ON` 不吸合；说 `pump=OFF` 反而一直转 | 通断档量 ESP32 GND 脚和模块 GND，必须 0Ω |
| 2 | 10k 漏了或接成下拉 | 复位/烧录时泵自己抽一下 | 每只 IN 到 5V_A 之间必须有 10k |
| 3 | **D1 装反** | 一上电就烧保险丝 | 有银环那端朝水泵 + 柱 |
| 4 | 继电器用了 **NC 触点** | 断电时泵反而在转 | 换到 COM + NO |
| 5 | 泵从降压板取电 | 降压板冒烟、泵欠压堵转 | 泵 12V 直连电池 |
| 6 | 4.7k 上拉到 5V | GPIO4 被打坏 | 必须拉到 3V3 |
| 7 | **排针数错一格** | 全乱 | 照附录，从最上面那个脚开始数 |
| 8 | 5V_A 和 5V_B 并成一条 | 继电器一吸合 ESP32 就复位 | 两条独立的 5V |

## 接完之后的验证

```
# 1. 只接电池 + 降压板，不接 ESP32：量 5V_A / 5V_B / 3V3 都对
# 2. 接 ESP32（USB 线先别插），上电，看板载灯
# 3. 插 USB 线到 USB 那个口，开串口 115200：

scan                       # 应列出 5 个探头 ROM
map skin_chest 0           # 把 1 号探头绑成"胸前体表"（自动存 NVS）
relay test                 # 每 5 秒翻一次 IN，用耳朵确认哪次咔哒
pump on                    # 强制开泵
pump off                   # 应该真的停 —— 停了才说明驱动方式对
enable on                  # 打开自动控温
status                     # reason 行会告诉你为什么开/不开
```
